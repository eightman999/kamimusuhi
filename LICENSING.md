# Licensing

Kamimusuhi is an open research project. This file explains the scope of the repository license and, especially, what it does **not** license.

## First-party material

Unless a file or directory states otherwise, first-party source code and first-party project documentation in this repository are distributed under the **MIT License** in [`LICENSE`](./LICENSE).

The MIT license covers material for which the Kamimusuhi copyright holder has the right to grant that license. It does not override licenses, terms of use, attribution requirements, database rights, privacy restrictions, or other conditions attached to third-party material.

## Third-party data, models, and services

External datasets, pretrained models, papers, images, APIs, websites, repositories, and other third-party resources retain their original terms. A reference, citation, download script, identifier, or interoperability adapter in this repository does **not** relicense the referenced resource under MIT.

In particular, raw or derived research data must carry provenance sufficient to identify:

- upstream source and version/snapshot;
- access or generation date when relevant;
- upstream license or terms;
- required citation/attribution;
- transformation or derivation steps;
- whether redistribution is permitted.

See [`data/README.md`](./data/README.md) and [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md).

## Papers and publication artifacts

A paper, preprint, figure set, or publication artifact under `papers/` may declare a separate license when required by an archive, publisher, conference, or journal. A local license notice inside a paper directory takes precedence for that publication artifact.

## Contributions

Contributors should not add third-party material unless its redistribution is compatible with the repository and its provenance and license are documented. When in doubt, commit code that obtains or transforms the material rather than committing the material itself.

This document is a repository policy, not legal advice.
