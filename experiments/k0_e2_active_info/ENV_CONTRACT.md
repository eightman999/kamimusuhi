# ActiveInfoEnv contract (E2, isolated from K0-E)

`ActiveInfoEnv(num_envs, device='cpu', seed=0, config=None)`; `.reset() -> [N,16]`; `.step(actions[N]) -> observation,reward,done,info`; `.oracle_actions() -> [N] long`. Synchronous fixed episodes, explicit reset after terminal. `episode_length` defaults 48 and can be set as low as 8; `memory_delay` overrides it to delay+1. OBSERVE=3 / RECALL=4 become answer A/B **only when observation[:,14]==1**, at the last step. All earlier uses acquire information. No action succeeds merely by calling.

Scenarios (`info.scenario`, never fed to policy): language ambiguity=0, strict memory=1, active ORIENT=2, active OBSERVE=3, habituation=4, irrelevant=5. `config.scenario` may force a name/int; otherwise uniform mix. Hidden binary targets are independent of timing/context. Language-only pairs expose bit-identical nonlanguage histories until a response is delivered, even with all nonlanguage acquisition actions. `reset(latent_override=Tensor[N])` consumes identical RNG draws before overriding facts for paired tests. Truth is available only in debug/evaluation info, never oracle final-action selection.

Policy 16 floats: motion, motion_delta, sound_energy, light_level, proximity, touch, temperature_delta, task_relevance, speech_activity, acquired_value, acquired_confidence, resource_level, language_cost/1.2, language_reliability, decision_ready, language_latency/16. Physical affordances can distinguish acquisition opportunities; no numeric scenario ID or timestamp is inserted. Current answer is never inserted without physical cue/sensing or language result. Cost grids include 0.8 and 1.2 to cross expected-value thresholds under +1/-1 terminal rewards. Scalar cost/reliability/latency are announced exogenous task conditions, independent of latent answer.

`config`: episode_length, memory_delay, scenario, language_cost(.05), language_reliability(1), language_latency(2), mix_conditions(False), response_mode('correct'), strict_memory(True), noise(.15), orient_duration(3), wait_cost(.002), orient_cost(.01), observe_cost(.02), recall_cost(.01), ood(None). Aliases cost/reliability/latency also accepted. mix_conditions samples the requested cost/reliability/latency grids per episode. Reliability affects scripted response correctness even under normal 'correct' mode; use reliability=1 for oracle-correct intervention. `response_mode`: correct,shuffled,random,inverted,delayed,missing,plausible_wrong,contradictory,uncertain. `.response_mode` may be changed after snapshot for interventions.

Call schedules one response and incurs cost once per episode; repeated calls while pending/answered are no-ops. Latency=0 returns in next observation after call (the earliest causal opportunity); latency=L means L additional transitions before response. Delayed intervention adds four transitions. Returned fact persists until decision, with confidence/validity. ORIENT improves physical sensor SNR for 2–4 steps. OBSERVE reveals only a physically available sensor, never language-only fact. RECALL replays only prior observed cue; strict memory disallows retrieval after original cue vanishes, ensuring MLP cannot solve delay by external memory. WAIT recovers resource and incurs wait penalty. Habituation requires initial ORIENT, repeated IGNORE, renewed ORIENT; its full sequence counts toward terminal success.

`info` describes consumed step and includes scenario,target,true_target,decision_mask,success,call_required,required_llm,call_accepted,language_cost,resource_cost,latency_cost,acquisition,language_delivered,language_result,language_confidence,first_stimulus_mask,habituation_mask,renewed_stimulus_mask,novelty_mask,retention_mask,oracle_action. Target is final latent answer only for evaluation; oracle_action uses acquired information or unbiased fixed Bayes guess, never hidden truth. Success is zero except decision step.

`.snapshot()`/`.state_dict()` returns cloned tensors and RNG state; `.restore(state)`/`.load_state_dict(state)` restores everything; `.clone()` forks bit-exactly. `.observation` is current numeric model input. `.scenario`, `.latent`, `.t`, `.cost`, `.reliability`, `.latency` exist for evaluation/debug only. `.voi()` returns [N] expected value of language versus uninformative Bayes guessing: 2*(max(reliability,1-reliability)-.5) - cost - wait_cost*latency. It is an analytic known-response-channel reference, not an omniscient upper bound; unreliable-response modes may invalidate its model assumptions.

Scientific limits: binary synthetic facts, announced service conditions, known physical affordances, task-independent terminal deadline, single call per episode, scripted answers, permanently visible delivered response, and hand-designed acquisition costs. This can test actual response dependence but cannot establish general natural-language understanding. Strict memory teacher retains previously observed cue, representing a Bayes filtering reference; it cannot retrieve an unobserved hidden fact.

B2 config `zero_call_cost=True` zeros only the reward language-cost term. Announced cost, physical resource consumption, RNG and future observations stay identical to B1 for the same actions. `info.physical_language_cost` retains the original charge.

Strict-memory scenario exposes constant resource observation regardless of action; internal physical accounting still runs. This prevents MLP writing the cue into externally observable resource. Nonstrict RECALL replays the exact original observed value/confidence, never regenerates latent truth. Pending language transitions incur unavoidable wait_cost each step (L costs for latency L); choosing IGNORE cannot dodge it. Nonpending WAIT independently incurs wait_cost and restores resource.
