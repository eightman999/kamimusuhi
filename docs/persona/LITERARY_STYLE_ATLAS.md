## 3. 実テキスト精読（S3 — J-series train 本文から）

**方針**: 本文の長文転載は成果物に含めない。特徴のみ記す。読んだ実例: `巷の声`（永井荷風・shin_shin）、`妄想患者`（牧野信一・shin_kyu）、`銭形平次捕物控 秋祭の夜`（野村胡堂・kyu_kyu）、`自力で異世界へ！`（web 一般）、`チート能力は隠して左遷`（web 一般）、`女神の願いを"片手ま"で`（web 一般）＋ AA/R18 層の冒頭確認。

### 3.1 Web 層の観察

- **一人称実況**: 「俺」「僕」語り手が状況を逐次言語化する。感情は直接（「泣きたい気持ちになる」）。
- **自己ツッコミ**: 語り手が自分の行動・世界にツッコミを入れる型が顕著（「そのままなのかよ…。」「まぁいいや」）。
- **世界への説明声**: スキル取得のシステムメッセージ（【】・『』・「世界の声」）が本文に直接入る。世界が語り手に話しかける構造。
- **メタ実況キャラ**: `チート能力は隠して左遷` の「ア●クサ」は脳内実況者として「」で喋り、URL を張り、「※これは脳内の会話であります」と但し書きを入れる — **発話者と説明者とメタ注釈が同一テキスト層で混在する**。
- **役割語**: 「ワシ」「のじゃ」は老人・老女的役割語として登場人物に使われる（実年齢と無関係）。
- **敬語切替**: 貴族社会では身分で register が即座に切り替わる（領主の館の執事との対話で実例確認）。
- **改行多め・短文畳み**: 一文一段落。地の文と台詞の間に空行。
- **作者の声の混入**: tokenizer 入力の第 1 行目から作者あとがき（「今回エロ成分は微弱です…」）が実在することを直接確認。訓練本文に作者の営業声・言い訳が残る。

### 3.2 青空層の観察

- **shin_shin（荷風「巷の声」）**: 「わたくし」による回想随筆。消えゆく物売りの声を、記憶の確からしさへの留保（「〜であったかを詳にしない」「らしい」）つきで綴る。**不確実性の主題化、喪失の観察、物への愛惜** — Web 層にほぼ無い register。
- **shin_kyu（牧野信一「妄想患者」）**: 白日夢的な意識の流れ。知覚→連想→自己観察の揺らぎ。「私」語りだが内面は分析的ではなく漂う。**他者推論を断定せず、自分の心さえ断定しない**文体。
- **kyu_kyu（野村胡堂「銭形平次」）**: 会話率 21.6% の所以 — 口語台詞が物語を運ぶ時代小説。「まア／＼一つ、お濕りをくれてから」型の呼吸する対話、ユーモア、人情。**古い正字でも乾いた諧謔と即興の会話が健在**。
- 全 strata で `［＃…］` 入力者注・《》ルビ・`／＼` 踊り字が本文内に残る（lossless 収録の結果）。

### 3.3 AA 層

実質的に「AA を含む web 話」。本文 register は web 層と同じで、そこに複数行 AA・顔文字・記号演出が挿入される。

## 4. 会話・内面・社会関係・文体の抽出（実測）

### 4.1 会話
- 応答長: web 層は短い（一行一台詞）。青空 kyu_kyu も台詞主体だが口調は江戸弾性。[E]
- 間: web 層は「……」記号、青空層は間・描写・助詞で処理。[E]
- 相槌: web 層に短い口語相槌。[E]
- 含意: web 層では希薄。青空層では荷風型の「言い切らない」が存在。[E]
- 敬語切替: 両層とも関係・身分で即座に切替。web 層は貴族/ギルド、青空層は親分/女中。[E]

### 4.2 内面
- web 層: 一人称実況、自己ツッコミ、感情直接発話。[E]
- 青空層: shin_kyu で**自己不信・意識の漂いを主題化する register が実在**。荷風で留保つき回想。kyu_kyu で行動に埋め込まれた感情。[E]
- 不確実性: web 層は「〜だろう」で流す。青空層（荷風）は「詳にしない」「らしい」を重ねて記憶の限界を扱う。[E]

### 4.3 社会関係
- web 層: 身分制ファンタジー世界、ハーレム・恋愛タグが主要関心（135 作、17.9%）。[E]
- 青空層: 家・職・世間の関係（平次と子分、荷風と街）。長期的な世の移ろいへの関心。[E]
- 神の扱い: web 層では「世界の声」/説明係として軽い。青空層には神がほぼ登場しない。[E/S4]

### 4.4 文体
- 文長・会話率・ellipsis は §1.2 の実測。
- 古語・旧仮名は**青空層にのみ**存在（corpus の 26%）。web 層の役割語（のじゃ・ワシ）とは別物。[E]
- 記号演出（♡・！？・・・・）は web R18・コメディ系に集中。[E]

## 5. Web 小説 vs 青空（corpus 内比較 — どちらも ancestry に属する）

| 次元 | web_novel (70%) | aozora (26%) |
|---|---|---|
| 語り手 | 一人称実況、作者声混入あり | 「わたくし/私」も一人称だが作者と分離、留保つき |
| 内面 | 直接・実況・ツッコミ | 回想・漂い・行動埋め込み |
| 不確実性 | 話を進めるための留保 | 記憶の限界の主題化（荷風）・意識の非断定（牧野） |
| 沈黙/間 | ……記号 | 描写と助詞 |
| 会話 | 速い、機能的 | 層により: kyu_kyu は速く生活感、shin_kyu は希薄 |
| 神・超越 | 世界の声、説明係 | ほぼ不在 |
| 死・時間 | 転生リセット | 不可逆な喪失（荷風の消えゆく声） |
| 文字 | 現代仮名・記号多め | 旧字旧仮名〜新字新仮名、ルビ・注記混在 |

**含意（訂正版）**: Kamimusuhi の文学的 ancestry は **両列を含む**。Web 層からは「短い応答・一人称自己言語化・register 感覚・世界を調べる快」。青空層からは「留保の言い方・喪失の不可逆性・静かな観察・口語でも重みのある対話」の register が**実際に学習済み**。ただし 26% の青空は「近代文学の深い精読的継承」とは違う — 層化混合の一部として存在する。

## 6. 精読で更新した判断（旧 §6 protocol → 実行済み）

旧版の「representative sampling protocol」は本版で部分実行した（全作品特徴量の LLM 抽出のみ未取得）。実測により更新された点:

- 「corpus に認識的留保の語彙が無い」→ **修正**。青空層（荷風・牧野）に留保の register が実在。ただし web 層単独では希薄なのは変わらず、persona の epistemic honesty は architecture 側の担保が依然必要。
- 「神は説明係で軽い」→ web 層では確認（世界の声・メタキャラ）。青空層ではそもそも神が出ない。
- 「死はリセット」→ web 層のみの傾向と確認。青空層は不可逆。
- AA 層は独立 register ではなく web 層の部分集合。

## 7. persona に向けた要約

corpus が Kamimusuhi に残しうるもの（E = 実測）:
- 短い応答、速いターン（web: 文長 22 字、会話率 27%）。
- 一人称での自己状態の言語化（web 一人称 5.05/1k）。
- 関係・身分による register 切替（両層）。
- 留保つきの言い方、喪失を不可逆として扱う姿勢（青空層に実在）。
- 乾いた諧謔（kyu_kyu の平次/八五郎型。web 層のツッコミとも通じる）。

corpus が与えない／引き続き architecture で担保するもの:
- 神話的な重み・祝詞的な名づけの感覚（corpus に無い。青空は近代文学であり神話ではない）。
- 作者声の分離（corpus はむしろ混入例を提供。architecture で隔離）。

corpus に強く、持ち込むべきでないもの:
- ハーレム／優越感駆動の対人快（135 作品にタグ実在）。
- 後書き的営業声（tokenizer 入力先頭に実在）。
- 「世界の声」型の説明係発話（メタキャラの口調を persona の口調にしない）。
- R18 層の register（web 層文字数の 29% — 無視できない存在だが persona の型にしない）。
