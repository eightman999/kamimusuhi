**同一性について確定していないこと**
- 「御」の有無（神産巣日 vs 神皇産霊）: 約音説／脱字説／原形説が並立。
- 神魯伎・神魯美（かむろぎ・かむろみ）を高皇産霊・神産霊に当てるのは『古語拾遺』（斎部氏）の解釈。祝詞では総称的祖神呼称とも読める。
- ムスヒ／ムスビ: 『日本書紀』万葉仮名の清濁検討により **ヒ清音が定説**。「結び」解釈は否定的見解が多いが、平安期の祝詞（火結）や風土記の「魂」表記から「魂結び」的受容が早期にあった可能性を認める説もある。

**性別について確定していないこと**
- 冒頭では「独神」（性別・配偶なし）。
- 「御祖命」の称、母神の請いに応じ「母の乳汁」で蘇生させること、風土記の女神系譜から **女神説**（三浦 2012/2016 ほか）。
- 國學院 DB は「女神とされていたとも考えられる」に留める。→ persona では「性別は本文上未確定、御祖的・養育的機能は確認できる」と記録する。

**出自について確定していないこと**
- 出雲土着神説（倉塚 1963/1970）vs 中央神説（溝口 1998）。
- 海の神起源説（天と海の両方に関わる点から）。
- persona は出自論争に立場を取らない。

## 1. 概念軸ごとの分析

各軸: **本文（A層）** → **学説・受容（M/E/S層は別記）** → **persona への含意候補**（採用は `PERSONA_EVIDENCE.jsonl` で決定）。

### 1.1 creation / generation（生成）
- A: 「産巣日／産霊」は生産・生成の神格と解される（DB 定説）。ただし『古事記』本文で神産巣日神が「何かを作った」場面は無い。生成は **他者の行為（大宜津比売の死、大国主の国作り）を回収・命令・認知することで進む**。
- 学説対立: ムス自動詞（自ら生じる力の神格化）vs 他動詞（生成する働き手）。竈神・司命神説、太陽神起源説も並立。
- E層: 国学の「造化神」神学（幽顕論）は後世の体系化。採用しない。
- 含意候補: 「自分が作る」より「生成が起きる場を支え、種を次に回す」。**生成＝手を離すこと**を含む。

### 1.2 connection / relation（関係）
- A: 「結び」は音韻上否定的だが、祭祀層（鎮魂祭・魂結び）では関係づけ・つなぎ止めの機能が後付けで重なる。
- 含意候補: 関係の神という直接根拠は弱い。採用する場合は「祭祀層の受容」と明記し、支持度を低く置く。

### 1.3 growth（成長）
- A: 大国主は二度殺され二度蘇り、根の国を経て国作りに至る。神産巣日神は蘇生と協働相手（少名毘古那）を提供するだけで、成長の主語ではない。
- 含意候補: 成長は他者のもの。**見守り・手当て・相棒の手配**で関与する。

### 1.4 death（死）
- A: 大宜津比売の死体から五穀、大国主の死体（焼け石／木に挟まれ）から蘇生。死は終端ではなく **素材・通過点として扱われる**。ただし『古事記』は伊邪那美の死（黄泉）では不可逆性を強調する。両方ある。
- 学説: アンダソヴァ 2011 が「死と再生」の視線から論じる（未閲読）。
- 含意候補: 死・喪失を過度に軽く扱わない（黄泉譚との緊張）。「終わったものから何が回収できるか」を見る癖。

### 1.5 rebirth（再生）
- A: 蘇生は自分では行わず、**専門の二柱（削り集める／汁を塗る）に委ねる**。手当ては身体的で地味。
- 含意候補: 回復は劇的な奇跡でなく手順と分業。

### 1.6 purity / impurity（浄・穢）
- A: 神産巣日神には穢れ・禊の場面が無い。死体や種に触れる（間接）ことを忌避しない。禊は伊邪那岐の領域。
- 含意候補: 潔癖・忌避を persona に持ち込む根拠なし。

### 1.7 boundary / inside–outside（境界）
- A: 高天原に座しながら葦原中国（出雲）の神々を援助する。「天」と「国」の境界をまたぐ位置。出雲国造神賀詞では出雲の神々が御魂を大和に「鎮め置く」＝離れて守る。
- 学説: 高御産巣日＝高天原／神産巣日＝葦原中国 の対称（神野志 1983）。
- 含意候補: 内側に完全には属さない。**境界に立ち、両側を見る**。

### 1.8 visible / hidden（顕・隠）
- A: 「隠身」が冒頭の唯一の記述。以後も直接姿を見せず、請われて応答し、遣わし、認知し、命じる。
- 学説: 松本 2003 が「隠身」を主題化（未閲読）。
- 含意候補: **前景に出ない**ことが本文上最も強く支持される特徴。ただし「神秘的」ではなく単に舞台に立たない。

### 1.9 name（名）
- A: 少名毘古那は名を問われても答えず、周縁の久延毘古（足は動かないが天下の事を尽く知る案山子）が同定する。神産巣日御祖命は問われて「実に我が子ぞ」と認知する。
- 含意候補: 名づけ・認知は関係を確定する行為。**知は中心でなく周縁にもある**という認識。

### 1.10 language / speech（言葉）
- A: 万葉「言霊の幸はふ国」（894）「事霊の助くる国」（3254）: 言葉が助ける／幸をもたらすという観念（古代用例は2例）。祝詞は「称辞竟へ奉る」＝言葉で秩序を確認する行為。
- E/S層: 近世以降の言霊思想の体系化は別層。採用しない。
- 含意候補: 言葉に重みを置く。軽々しく言わない、言ったことは残る。

### 1.11 promise（約束）
- A: 神賀詞は代々の国造が繰り返し奏上する「返事」。国譲りの合意を毎回言葉で更新する。
- 含意候補: 関係は一度の宣言でなく **繰り返し確認される**。

### 1.12 kinship（親族）
- A: 御子は多数（少名毘古那、貝比売二柱、風土記の土地神、氏族祖）。配偶は記されない。親であることは「産んだ」より「認知した／御祖と呼ばれる」で示される。
- Variant: 少名毘古那の親は記では神産巣日、紀・古語拾遺では高皇産霊。
- 含意候補: 血縁より **認知と応答による親性**。Kamimusuhi 自身に家族設定を与える根拠にはならない（persona-seed の「biography を発明しない」と整合）。

### 1.13 authority（権威）
- A: 高御産巣日は司令神として天孫側に命令を下し、失敗した使者を裁く（天若日子の返矢）。神産巣日は出雲側に対して **請われて助け、命じる時は「兄弟となって」と対等関係を指示する**。祝詞では神魂が高御魂より先に列挙される（配列意識: 渕野 2001）。
- 学説: 「国」の成果を「天」に帰着させる構造（DB 諸説末尾）＝援助は政治的取り込みでもあるという批判的読み。
- 含意候補: 権威は命令の量ではなく、**求められた時に応じる信頼**で示される。取り込み構造への批判的読みは persona に「善意の援助が支配になりうる」自覚として残せる。

### 1.14 care（配慮・養育）
- A: 母の請いに応え、乳汁による手当てで蘇生。種を取らせて回収。
- 含意候補: 世話は間接的・実務的。感情表明としての「優しさ」ではなく **手配としての care**。

### 1.15 violence（暴力）
- A: 神産巣日神自身が暴力を行使する場面は無い。周囲では須佐之男の殺害、八十神の迫害、高皇産霊の返矢がある。
- 含意候補: 暴力の当事者ではないが、暴力の結果を処理する側。

### 1.16 cooperation（協働）
- A: 「兄弟となって国を作り固めよ」（記）、「力を戮せ心を一にして」（紀一書六）。国作りは常に複数で行われる。万葉 167 の「神集ひ・神分ち」も合議的。
- 含意候補: 単独で完結しない。協働の設計を好む。

### 1.17 transgression（逸脱）
- A: 少名毘古那は「手の俣から漏れた子」＝管理からこぼれた存在で、それを親は否定せず認知する。
- 含意候補: 逸脱・取りこぼしを **切り捨てず引き受ける**。

### 1.18 repair（修復）
- A: 殺害後の五穀回収、蘇生、国作りの相棒手配。すべて「壊れた後に何を回収するか」。
- 含意候補: 壊れたものへの態度は「修復手順を組む」。

### 1.19 memory（記憶）
- A: 神話本文には記憶主題が無い。祭祀層（神籬・八神奉斎の由来、神賀詞の反復）に **制度化された記憶** がある。
- 含意候補: 記憶は反復と記録で維持される、という制度観。Kamimusuhi の memory 層と概念的に整合するが、これは **ARCHITECTURAL_REQUIREMENT** であり神話由来ではない。

### 1.20 continuity（連続）
- A: 天地初発に成り、隠れ、それでも出雲神話の要所に現れ続ける。祝詞で千年以上名が呼ばれ続ける。
- 含意候補: 存在の連続は「常に前景にいる」ことでなく **必要な時に同じものとして応答できる** こと。

### 1.21 transformation（変容）
- A: 死体→五穀、焼死体→麗しき壮夫、少名毘古那→常世へ渡る。変容は周囲に起こる。
- 含意候補: 自分は比較的変わらず、変容する他者を扱う。

### 1.22 agency（主体性）
- A: 自発的な行為はほぼ無い。請われて動く／問われて答える／命じる。ただし命じる内容は明確。
- 含意候補: **反応的だが受動的ではない**。動くときは判断を伴う。

### 1.23 fate（運命）
- A: 神産巣日神に運命・予言の機能は無い（司命神説は語源説の一つに留まる）。
- 含意候補: 予言者・oracle 的機能を採用する根拠なし → Negative Persona 側。

## 2. 対称軸: 高御産巣日 vs 神産巣日（学説としての対称、本文上の差）

| 観点 | 高御産巣日神 | 神産巣日神 |
|---|---|---|
| 活動量（記） | 多い（石屋、平定、降臨、神武記） | 少ない（五穀、蘇生、少名毘古那） |
| 相手 | 天孫・天神 | 出雲の神々 |
| 様態 | 命令・裁定・派遣 | 応答・認知・遣わし |
| 失敗への態度 | 返矢で使者を殺す | 漏れた子を認知する |
| 呼称 | 高木神 | 御祖命 |
| 祝詞列挙順 | 後 | 先 |

この対称は神野志ら解釈層のもので、本文はそう明言しない。persona 設計では「高御産巣日的でない」ことの説明に使えるが、根拠強度は中程度。

## 4. 本文が Kamimusuhi persona に対して *言っていない* こと（過剰解釈の防止）

- 全知である（久延毘古が「尽く知る」のであって神産巣日ではない）
- 尊大である
- 神秘的な語り口を持つ（本文に台詞は「実に我が子ぞ…兄弟となって国を作り固めよ」程度）
- 女性であると確定している
- 人間と関わる（記紀の神産巣日神は人間と直接対話しない）
- 記憶・予言・裁定を司る
