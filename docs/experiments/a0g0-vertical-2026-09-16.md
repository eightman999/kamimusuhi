## Graft（G0）

- `graft/schema.py`: `GraftSpec` / `Graft` / `GraftLink` /
  `HostSelector`（neuropil・cell_type・flow_class・super_class・
  dataset_ids 指定、max_targets+seed で決定的サブサンプル）
- `graft/build.py`: selector を canonical store へ解決し、既存の
  phenotype（`artificial_organs`+`attachments`）へコンパイル。
  `enabled=False` で非破壊 ablation。link 毎の `p`・`weight`・
  `direction`（in/out/bidirectional）対応。
- namespace 分離: 宿主は `banc:<root_id>`、graft は
  `graft:g001:n<idx>`（§19）。
- G0デモ: 10ニューロン再帰 lobe、in-link = afferent sensory port
  （64細胞）、out-link = descending 細胞（64細胞）。
  - **in-link 重み 15 / out-link 20**（MODEL_INFERENCE・graft設定値）:
    alphaシナプス経由の LIF で閾値差 7mV を跨ぐには定常 g ≈ 7mV が
    必要で、wScale 0.275mV の単イベントでは到達不能。
    駆動 afferent 32入力×30Hz で g_ss ≈ 10mV となるよう設定。
  - **重要な教訓**: graft の宿主標的を ~12k afferent から seed 抽出
    すると、実際に駆動する256細胞とほぼ非重複になり「graft沈黙」の
    偽陰性を生む。runner は graft の in-link 解決済み標的を駆動集合に
    必ず含める（`must_include`）。

## 結果（300ms × 2 replicate、seed 20260916）

| 条件 | propagated edge events | graft spikes/lane | 全体 mean rate |
|---|---|---|---|
| host + graft | 261,615 | [75, 76]（≈25 Hz/cell）| 0.0381 / 0.0388 Hz |
| host のみ（ablated）| 252,901 | — | 0.0369 / 0.0376 Hz |

- host→graft: 駆動 afferent → graft 発火を確認（`organ:graft:g001`
  ≈ 25 Hz）
- graft→host: out-link 辺を実際にイベントが伝播（edges +8,714）。
  host spike への因果効果はこの駆動規模では微小（fba0 rate 差
  ~4e-7 Hz）— graft バーストが宿主細胞を発火させるには更なる
  重み・収束が必要で、これは G1 以降の課題として記録する
- **paired ablation**: 同一 seed・同一駆動で full vs graft-disabled を
  比較可能（`delta_rate_hz_per_lane` / `delta_fba0_rate_hz_per_lane`
  を両方記録。graft 自身の活動が all-mean を押し上げる分を分離）
- **決定性**: 同一 spec+seed の再実行で per-lane spike count が完全一致
- wall: full ≈ 6.0s / ablated ≈ 5.2s / 300ms・2レーン（M-series CPU）

## 制限・既知の未実装

- morphology は `morphology_ref` slot のみ（BANC edgelist/meta に形状
  本体なし）— UNKNOWN として保持、A2 compartment compiler は未着手
- 宿主内の活動は 300ms・256 afferent 駆動では疎（~0.037Hz）:
  単一実シナプス ~0.275mV vs 閾値差7mV のため収束入力が必要。
  生理的には正常だが、行動ループ評価にはより強い駆動か
  virtual body の感覚相関が要る（§13 は未実装）
- gap junction・神経調節・実測膜パラメータは全て UNKNOWN 保持
- weight は anatomical_count 由来の MODEL_INFERENCE であり実測
  conductance ではない（§6.5）
- 座標は 169k/204k 細胞のみ。欠損細胞は view 上 UNKNOWN として扱い
  推定座標は置かない
