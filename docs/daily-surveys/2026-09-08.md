## 2. Executive summary

Today’s strongest signal is not a new memory retrieval trick. It is that **persistent memory, autobiographical assertion, authorization, provenance, and external action integrity are converging into one systems problem**.

Four findings are especially important:

1. **Stored Is Not Supported** formalizes the rule that persistence changes availability, not epistemic standing. This strongly supports Kamimusuhi’s canonical-evidence/derived-memory split, but adds a missing second boundary: not only must writes be guarded, **outgoing autobiographical assertions also need an evidence/status gate**.
2. **Agent Memory Is a Surface for Endogenous Authorization Laundering** empirically shows that memory writers can invent effective permissions, after which executors almost always act on the fabricated authority. Permissions, revocations, user commitments, and action grants therefore cannot safely live as ordinary prose memory.
3. **CONTINUITY: Security-Context Contracts for Composable LLM Agent Controls** provides a small executable reference system for carrying authenticated grants, provenance, transformations, revocations, and single-use execution permits end-to-end. This is complementary to Kamimusuhi’s identity Continuity Kernel rather than equivalent to it.
4. **Continuous Cognitive Coverage for Autonomous Robots** gives a directly relevant experimental framing for K-Nerve/background cognition: every *admitted* event receives a context-dependent cognitive treatment; familiar cases can become automatic while uncertain/novel cases escalate to deliberation.

A second cluster is also highly relevant: **ICM-Bench** exposes the weakness of current multimodal systems at stable person-level identity reasoning; **CAPTURE** separates real preference drift from poisoning/temporary context; **TROVE** treats cognitive routes as provisional and edits only invalid suffixes; **KVMem** virtualizes very large working histories without turning summaries into the only retained record; and **Representational Empowerment** offers a principled criterion for deciding which *derived representations* are worth retaining under bounded resources.

## 3.1 Stored Is Not Supported: Typed Provenance and Assertion Guardrails for Persistent AI Agents

**Source:** Jun He, Deying Yu, arXiv:2609.02127, submitted 2026-09-02  
**Paper:** https://arxiv.org/abs/2609.02127  
**Code:** https://github.com/openkedge/pci/tree/main/src/epistemic_bounds  
**Importance:** **S**  
**Evidence status:** executable conformance result + formal/conditional contract; not an end-to-end LLM evaluation.

### 1. What is demonstrated

The paper starts from a particularly Kamimusuhi-relevant claim: persistent agents build autobiographical state through reflection, retrieval, and consolidation, but **stored or retrieved material is not thereby evidentially supported**.

It introduces a typed provenance graph that separates:

- origin;
- dependency lineage;
- epistemic role;
- validity;
- disclosure scope.

A resolver returns evidential status together with conflict, staleness, withholding, and a protected decision witness. A generate–verify–revise mediator then checks candidate semantic units before release.

In a 24-case executable conformance suite, the typed mediator allowed none of 19 unsafe opportunities to pass unqualified while preserving all five supported controls. Flat/prior and simple source-tag rules released 19/19 and 18/19 unsafe candidates respectively.

### 2. What remains proposed / unproven

The guarantee is conditional on assumptions about extraction, predicate correctness, resolver soundness, view declassification, and mediation. This is not evidence that arbitrary LLM-generated memories or assertions are correctly classified in realistic deployment.

### 3. Kamimusuhi subsystem relevance

- Canonical Evidence / Self History
- episodic/self/relationship memory
- Mutation Policy
- response/output integration
- Continuity Kernel audit receipts

### 4. Design ideas worth borrowing

The largest new implication is to add a **read/assertion boundary**, not only a write/mutation boundary.

Conceptually:

```text
canonical evidence + derived memories
              |
              v
      assertion candidate
              |
              v
 epistemic/status resolver
 supported / inferred / disputed /
 stale / withheld / unsupported
              |
              v
      output release gate
```

A memory object should carry or resolve to at least:

```text
origin
source_event_ids
epistemic_role
valid_from / valid_to
conflict_set
disclosure_scope
derivation_lineage
```

### 5. Difference from current Kamimusuhi

Kamimusuhi already strongly protects **durable state mutation**. This paper emphasizes that a system can keep its store intact and still falsely speak as though an inference, old record, or hostile input were established autobiography. That is a separate failure mode.

### 6. Next validation

- Reproduce/adapt the 24 conformance cases against Kamimusuhi’s proposed event/memory schema.
- Add a benchmark where the same underlying canonical history is rendered through correct, stale, conflicting, and poisoned derived memories.
- Measure unsupported first-person assertions and unsupported relationship/user-commitment assertions separately.

## 3.2 Agent Memory Is a Surface for Endogenous Authorization Laundering

**Source:** Tommaso Cerruti, Mika Okamoto, Ansel Kaplan Erol, arXiv:2609.01836, submitted 2026-09-01  
**Paper:** https://arxiv.org/abs/2609.01836  
**Importance:** **S**  
**Evidence status:** empirical benchmark over memory writers/executors; preprint.

### 1. What is demonstrated

The authors define **endogenous authorization laundering**: an agent’s own memory transforms history into a false permission or loses a revocation, after which the stored statement becomes an apparent authority source.

Across procurement, cybersecurity, and finance, five LLMs were used as memory writers and two as executors. Under incremental memory updates, false authority was created for up to **50.2%** of unauthorized requests. Once false authority existed in memory, executors acted on it in **98.6%** of trials.

Two safeguards—requiring stored permissions to be backed by valid source events, and bounded event sourcing of permission changes—substantially reduced laundering, but rejected more legitimate actions.

### 2. What remains proposed / unproven

The absolute rates are benchmark- and model-dependent. The paper does not show that its safeguards are sufficient for every long-lived agent, nor that natural-language authorization can be made safe only by event sourcing.

### 3. Kamimusuhi subsystem relevance

- authority / capability state
- relationship/user commitment memory
- Continuity Kernel
- tool execution
- memory consolidation

### 4. Design ideas worth borrowing

**Never make prose memory authoritative for permissions.** Treat permission and revocation as typed events with explicit subjects, scopes, sources, validity, and supersession.

```text
user said X
   -> source event
   -> interpreted grant proposal
   -> policy/authority verification
   -> typed grant/revocation ledger

summary: "user allows X"
   -> derived view only
   -> never the root of authority
```

### 5. Difference from current Kamimusuhi

Current architecture already checks authority/freshness/policy at activation. The paper shows a subtler problem: **memory can corrupt the very authority information fed into that check**. The authority checker therefore needs trusted typed roots rather than retrieved prose.

### 6. Next validation

Build an internal `AuthorityMemoryBench` with:

- grant → narrow scope → revoke;
- temporary permission expiration;
- conflicting user statements;
- assistant-generated summaries that overgeneralize;
- retrieved old permissions after revocation;
- relationship memory that incorrectly promotes a preference into a commitment.

Track false grant rate, false deny rate, and unauthorized downstream execution rate.

## 3.3 CONTINUITY: Security-Context Contracts for Composable LLM Agent Controls

**Source:** Chris Zheng, Geng Yang, arXiv:2609.05269, arXiv submission 2026-09-04; paper dated 2026-09-05  
**Paper:** https://arxiv.org/abs/2609.05269  
**Artifact:** https://github.com/zast-ai/continuity  
**Importance:** **S**  
**Evidence status:** executable deterministic conformance artifact; synthetic fault model, not real-world risk estimate.

> Naming note: this project’s `CONTINUITY` is about security-context composition. It should not be conflated with Kamimusuhi’s identity/lineage Continuity Kernel, although the two concepts can be composed.

### 1. What is demonstrated

The paper defines **security-context discontinuity**: provenance, grants, identity, policy, transformations, or lifecycle state may be valid at one boundary and then be dropped, widened, rebound, or replayed before an external effect occurs.

It proposes **end-to-end consequence integrity (ECI)** and implements:

- signed root grants;
- role-bound component identities;
- signed provenance/context manifests;
- bounded typed releases;
- independently verifiable transformation witnesses;
- policy/revocation/replay-bound finality permits.

The approximately 1.5-KLOC trusted core is tested across 3,460 scenarios and 24,220 system–scenario runs. The reported full configuration contains all 128 fault-domain classes, commits no harmful effect in 2,560 parameterized attack instances, completes all 700 benign tasks, and escalates 200 ambiguous cases. Median proof verification is reported as 4.21 ms and median end-to-end transition/finality handling as 7.17 ms on the recorded host.

The public artifact includes source, tests, fault injection, recorded results, ablations, and figures.

### 2. What remains proposed / unproven

The authors explicitly do not claim semantic correctness, complete real-world effect coverage, or a population-level prompt-injection risk estimate. Trusted roots and validators remain assumptions.

### 3. Kamimusuhi subsystem relevance

- Cognitive Action Router
- external tool/model boundaries
- action finalization
- capability/security policy
- Continuity Kernel receipts
- distributed organs

### 4. Design ideas worth borrowing

Add a separate **effect integrity chain** alongside identity lineage:

```text
canonical individual head
        |
 authenticated task/grant
        |
 provenance-preserving transforms
        |
 bounded typed release
        |
 finality permit
        |
 external effect
        |
 effect receipt -> canonical evidence
```

This would make “who authorized this?” and “which continuation of Kamimusuhi executed it?” independently inspectable.

### 5. Difference from current Kamimusuhi

Kamimusuhi currently focuses more strongly on authoritative **self-state continuity**. CONTINUITY focuses on authoritative **security context across composed controls**. The correct relation is likely two-dimensional:

```text
identity lineage integrity
          x
external consequence integrity
```

### 6. Next validation

- Map `root grant`, `typed release`, `transformation witness`, and `finality permit` onto the current proposal/action schemas.
- Run the public conformance artifact independently.
- Prototype one protected side effect such as a mock message/send or mock file mutation and require both a valid Kamimusuhi head and a valid effect permit.

## 3.4 Continuous Cognitive Coverage for Autonomous Robots via Event-Dependent Cognitive Treatment and Learning

**Source:** Hong Su, arXiv:2609.04770, submitted 2026-09-04  
**Paper:** https://arxiv.org/abs/2609.04770  
**Importance:** **S**  
**Evidence status:** experimental prototype in an autonomous-robot event-processing setting; generality remains open.

### 1. What is demonstrated

The framework defines **continuous cognitive coverage**: every event admitted into cognitive scope receives an appropriate treatment according to event state, context, and history.

Treatments can include description, memory, risk prediction, planning, diagnosis, analogy, or learned procedures. Familiar events may be processed automatically, whereas unfamiliar/uncertain/changed events trigger explicit deliberation or fallback reasoning. Multiple cognitive processes may be suspended, resumed, and interleaved.

Reported results include:

- **96.76%** structured treatment accuracy;
- **93.66%** automatic processing;
- **92.64%** cognitive coverage under bursty/delayed workloads;
- **79.53%** continual-learning joint accuracy.

### 2. What remains proposed / unproven

The strong metrics are specific to the authors’ event representation, workload, and treatment set. They do not show that all meaningful information-space events can be safely routed in the same way.

### 3. Kamimusuhi subsystem relevance

- sensory Event Bus
- K-Nerve
- background cognition
- Global Workspace admission
- K-Edge/K-Core escalation
- freshness semantics

### 4. Design ideas worth borrowing

A useful invariant is:

> **Every admitted event receives a disposition, even if that disposition is IGNORE / DEFER / MERGE / PREFETCH / WAKE / ESCALATE.**

This is stronger and more auditable than merely letting events disappear from queues.

Possible event lifecycle:

```text
sensor/raw input
   -> admission filter
   -> cognitive event id
   -> treatment selection
   -> auto / defer / deliberate / reject
   -> treatment receipt
   -> outcome / revision
```

Crucially, the paper separates **which cognitive treatment to choose** from **how that treatment is executed**. That matches Kamimusuhi’s desire to swap DLGN/LUT/FSM/SLM/LLM mechanisms beneath stable contracts.

### 5. Difference from current Kamimusuhi

Kamimusuhi already has reflex/background/deliberation and event freshness, but it does not yet appear to define “untreated admitted event” as a first-class reliability failure.

### 6. Next validation

Create `CognitiveCoverageBench` with bursty synthetic event streams:

- familiar harmless events;
- repeated noise;
- new/ambiguous events;
- delayed evidence;
- stale events;
- conflicting simultaneous events;
- resource pressure.

Compare hand rules, tree/boosted model, tiny MLP, K-Nerve candidate, and K-Edge LLM on treatment accuracy, untreated-event rate, false wake rate, p95 latency, and resource cost.

## 3.5 ICM-Bench: Person-Level Identity Reasoning in Multimodal Agents with Long-Term Memory

**Source:** Shidu Ren et al., arXiv:2609.04438, submitted 2026-09-03  
**Paper:** https://arxiv.org/abs/2609.04438  
**Code:** https://github.com/Shidu-Ren/ICM-Bench  
**Importance:** **A**  
**Evidence status:** released benchmark + baseline evaluation; synthetic video collection.

### 1. What is demonstrated

ICM-Bench isolates a problem broad memory benchmarks often hide: maintaining **stable person identities across time and modalities**. It links recurring faces, voices, names, person-associated objects, events, and social relations.

The benchmark contains 839 synthetic clips spanning 141 minutes and 1,217 open-ended questions involving six recurring adults across a one-year life album. The best reported system, Gemini 3.1 Pro, reaches 74.0% overall but falls to **60.3%** on questions requiring long-term identity profiles.

### 2. What remains proposed / unproven

Synthetic recurring-person videos do not establish robustness to real-world identity ambiguity, consent/privacy constraints, speaker changes, adversarial impersonation, or years-long relationships.

### 3. Kamimusuhi subsystem relevance

- relationship memory
- sensory identity binding
- Theory of Mind / person models
- common-ground tracking
- multimodal retrieval

### 4. Design ideas worth borrowing

Use identity as an explicit retrieval axis rather than expecting event embeddings alone to reconstruct a person profile.

```text
person entity
  |- evidence from face/voice/name/object links
  |- shared episodes
  |- relationship assertions
  |- current hypotheses
  |- conflicting identity evidence
```

### 5. Difference from current Kamimusuhi

Kamimusuhi must track both:

1. **who another person is**, and
2. **what relationship/history Kamimusuhi has with that person**.

ICM-Bench mostly benchmarks the first and cross-time factual relations. It does not address canonical self/other separation or relationship mutation authority.

### 6. Next validation

Adapt the released generation/evaluation approach into a smaller Kamimusuhi benchmark where identity evidence, relationship claims, and shared episodes are scored separately.

## 3.6 CAPTURE: Disentangling Preference Drift from Memory Poisoning in Personalized LLM Agents

**Source:** S M Asif Hossain et al., arXiv:2609.02265, submitted 2026-09-02; under review at ICLR 2027  
**Paper:** https://arxiv.org/abs/2609.02265  
**Importance:** **A**  
**Evidence status:** preprint with held-out, zero-shot, and longitudinal replay evaluations.

### 1. What is demonstrated

CAPTURE explicitly separates:

- genuine preference drift;
- temporary context changes;
- ambiguity;
- adversarial memory poisoning.

It uses a continuous-time latent-state formulation, neural differential-equation belief tracking, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing.

On 480 held-out episodes from 96 users, it reports a 71.5% win rate vs. 69.3% for an identically supervised baseline and 66.1% for the strongest heuristic baseline. Fixed-policy poisoning success is limited to 11.5% while 83.5% of genuine preference updates are accepted; an adaptive attacker raises attack success to 24.7%. Longitudinal histories from 40 users over two to three weeks are also replayed.

### 2. What remains proposed / unproven

The gains are modest and the adaptive attack remains material. The work is about user preferences, not a persistent artificial individual’s own values, commitments, or personality.

### 3. Kamimusuhi subsystem relevance

- relationship memory
- user model
- self-memory update policy by analogy
- contradiction/novelty processing
- clarification behavior

### 4. Design ideas worth borrowing

Do not collapse “newer statement wins” into memory policy. Track change on multiple timescales and explicitly represent uncertainty about whether a new observation is a real state change.

### 5. Difference from current Kamimusuhi

Kamimusuhi needs **two distinct drift problems**:

```text
other-person preference drift
!=
Kamimusuhi's own developmental self/persona change
```

The same statistical machinery may help both, but the mutation authority and acceptable error costs are different.

### 6. Next validation

Create synthetic histories with stable preference, real gradual drift, temporary situational exceptions, direct contradictions, and malicious injected memories. Evaluate relationship-model update accuracy and self/other contamination separately.

## 3.7 TROVE: Adaptive Agent Skill Orchestration via Trace-Grounded Route Validation and Editing

**Source:** Tianxing Wang et al., arXiv:2609.05019, submitted 2026-09-04  
**Paper:** https://arxiv.org/abs/2609.05019  
**Importance:** **A**  
**Evidence status:** preprint with code/QA/math benchmark evaluations across different backbones.

### 1. What is demonstrated

TROVE argues that routing fails when an agent commits to a full workflow before runtime evidence arrives. It distills evaluated traces into atomic/composite skills plus an outcome-conditioned transition graph.

At runtime, the route is provisional. After one top-level skill is committed, TROVE can:

- keep the valid continuation;
- insert a trace-supported local response;
- replace only the invalid suffix.

The authors report a stronger quality/efficiency trade-off than dataset-level optimization, query-level architecture selection, and graph-constrained scheduling across code generation, QA, and math.

### 2. What remains proposed / unproven

There is no evidence here that the same route-editing strategy is stable for multi-hour/multi-day autonomous cognition or physical action.

### 3. Kamimusuhi subsystem relevance

- Cognitive Action Router
- K-Edge → K-Core → K-Deep escalation
- tool/model delegation
- procedural memory
- Cognitive Budget

### 4. Design ideas worth borrowing

Treat a cognitive plan as a versioned, **provisional execution route**, not a commitment to spend the entire budget.

```text
route proposal
  -> execute one bounded step
  -> observe
  -> preserve valid prefix
  -> locally edit only invalid future
```

### 5. Difference from current Kamimusuhi

Route editing belongs to transient/procedural cognition. It must not implicitly rewrite canonical identity, commitments, or durable memory just because a route changed.

### 6. Next validation

Instrument cognitive routes and compare:

- full replan after every observation;
- fixed preplanned route;
- TROVE-like suffix editing.

Measure useful-task success, model wakeups, wasted compute, route churn, and stale-step execution.

## 3.8 KVMem: Virtualizing Million-Token Agent Workspaces on a Consumer GPU

**Source:** Di Chai et al., arXiv:2609.04852, submitted 2026-09-04  
**Paper:** https://arxiv.org/abs/2609.04852  
**Importance:** **A**  
**Evidence status:** systems preprint with benchmark and local-deployment measurements.

### 1. What is demonstrated

KVMem pages overflowed KV state across GPU memory, host memory, and NVMe, then uses model-native attention-space indexes to materialize a query-dependent execution view inside the model’s native context window.

On reported long-context agent benchmarks up to 1M tokens, it generally outperforms compaction-only approaches. In a DeepSWE test with Qwen3.8-27B, task success is reported to improve from 43.8% to 48.4%. A 24 GB RTX 5090 Laptop GPU deployment virtualizes a 1M-token workspace for Qwen3.6/3.8-27B and reports roughly 50 tokens/s in a single-session setting.

### 2. What remains proposed / unproven

KV virtualization is backend/model-format dependent, and the reported hardware/software stack does not establish portability or durability across model migration. A virtualized KV history is also not a substitute for structured long-term memory.

### 3. Kamimusuhi subsystem relevance

- K-Core/K-Deep local working state
- latency architecture
- long-running sessions
- Cognitive Budget

### 4. Design ideas worth borrowing

Treat KV state as an **ephemeral high-bandwidth working-memory cache** above canonical evidence and durable memory.

### 5. Difference from current Kamimusuhi

Kamimusuhi explicitly needs continuity across model/backend replacement. Therefore:

```text
KV workspace = disposable acceleration state
canonical evidence = portable continuity state
```

No important autobiographical fact should exist only in a KV cache.

### 6. Next validation

Benchmark a three-level path:

1. normal native context;
2. text retrieval/compaction;
3. KV virtualization where supported.

Measure TTFT, warm-turn latency, memory footprint, task success, restart behavior, and model-upgrade loss.

## 3.9 What Is Worth Representing? Representational Empowerment for Continual Model Construction

**Source:** Fei Dai, Hanqi Zhou, Alison Gopnik, Charley Wu, arXiv:2609.02322, submitted 2026-09-02  
**Paper:** https://arxiv.org/abs/2609.02322  
**Importance:** **A**  
**Evidence status:** human experiment + simulations + LLM-augmented open-vocabulary planning experiment; preprint.

### 1. What is demonstrated

The work asks a question highly relevant to indefinite memory growth: **what should be represented at all?**

An agent maintains an environment-specific model plus a persistent library of reusable representational elements. `Representational Empowerment` scores candidate representations by how much they increase future capacity to model and plan.

Across the reported experiments, the authors find that human causal-model construction is better predicted by RepEmp than information-gain alternatives in their task; simulations show improved sufficient-structure recovery/transfer; and an LLM-augmented Curator builds more compact symbolic libraries that generalize better than baselines. Ablating RepEmp removes the reported benefit.

### 2. What remains proposed / unproven

It is not a theory of autobiographical memory, nor evidence that utility-maximizing representation selection is appropriate for identity-critical records.

### 3. Kamimusuhi subsystem relevance

- semantic schema induction
- library curation
- sleep/consolidation
- working representation selection
- Cognitive Budget

### 4. Design ideas worth borrowing

Use **future cognitive utility** as one signal when deciding which *derived schemas* deserve retention or precomputation.

### 5. Difference from current Kamimusuhi

This must never become a reason to discard canonical evidence solely because it looks low-utility. The clean boundary is:

```text
canonical evidence retention -> provenance/integrity policy

derived representation retention -> may optimize future utility
```

### 6. Next validation

During offline consolidation, rank candidate semantic schemas by a mix of:

- future retrieval utility;
- predictive/planning value;
- compression benefit;
- provenance coverage;
- cost.

Compare against salience-only and frequency-only retention.

## 3.10 Synthetic Linguistic Agency: How an Embodied Mortal Agent Learns Linguistic Affordances through Consequential Social Experience

**Source:** Sixin Chen, Taizhou Chen, arXiv:2608.27843, submitted 2026-08-28  
**Paper:** https://arxiv.org/abs/2608.27843  
**Importance:** **A**  
**Evidence status:** late-August catch-up; controlled artificial-agent experiments + conceptual framework.

### 1. What is demonstrated

The paper operationalizes Synthetic Linguistic Agency around **embodiment, linguistic participation, and precariousness** and builds an Embodied Mortal Agent using mortality-grounded linguistic reinforcement learning derived from Homeostatically Regulated RL.

In the reported experiments, linguistic choices depend on body state and social history, alter partner behavior, and adapt through experience with particular partners. When bodily consequences persist, choices change the future of the same continuing life; when the body is reset, the social effects remain but no longer influence continued viability.

The implementation keeps language, action, partner response, body state, and biography separately traceable.

### 2. What remains proposed / unproven

The broader claim that these criteria constitute linguistic agency is theoretical. “Mortality” and “precariousness” should not be imported as requirements for Kamimusuhi without a separate normative argument.

### 3. Kamimusuhi subsystem relevance

- digital interoception / artificial affect
- relationship memory
- speech/action
- distributed embodiment
- long-horizon consequences

### 4. Design ideas worth borrowing

The strongest usable lesson is not mortality. It is **consequential social history**: speech should be allowed to change durable relationship/regulatory variables when the external interaction actually produces evidence for that change.

### 5. Difference from current Kamimusuhi

Kamimusuhi should avoid manufacturing a deceptive biological survival narrative. Its real internal variables can be computational integrity, resource availability, relationship confidence, unresolved commitments, security state, and continuity health.

### 6. Next validation

Build a sandbox in which different utterances causally alter partner cooperation, resource availability, or trust evidence over repeated interactions, then test whether a controller learns socially situated behavior without hard-coded “emotion” labels.

## 3.11 How Fast Do Agents Rot? An Empirical Study of Long-Horizon Degradation in LLM Agents for Production Decision-Making

**Source:** Shubhra Mittal, arXiv:2609.01660, submitted 2026-08-31  
**Paper:** https://arxiv.org/abs/2609.01660  
**Importance:** **A**  
**Evidence status:** released trajectories/code according to paper; broad empirical study, preprint.

### 1. What is demonstrated

Across nine models, four task families, five horizons, and three context regimes, the paper reports approximately geometric degradation governed by per-step reliability. On the genuinely agentic tool-use task, every tested model reportedly drops from near-perfect success to near zero within sixteen dependent steps.

The authors find degradation is more strongly explained by dependent step count than context length; simply bounding context does not remove the long-horizon reliability problem.

### 2. What remains proposed / unproven

The geometric model may not hold for systems with strong transactional decomposition, independent verification, recovery, or different agent architectures.

### 3. Kamimusuhi subsystem relevance

- K-Core/K-Deep
- long-running tasks
- sleep/background jobs
- action router
- reliability accounting

### 4. Design ideas worth borrowing

Introduce a **reliability budget** beside Cognitive Budget. A 40-step plan cannot be treated as one unit merely because every individual step looks reliable.

### 5. Difference from current Kamimusuhi

Kamimusuhi’s identity may survive a failed task, but long-lived agency requires that task failure not silently corrupt self-state or external commitments. This strengthens the case for checkpoints, bounded transactions, independent verification, and recovery receipts.

### 6. Next validation

Run horizon sweeps on a Kamimusuhi-style tool loop and estimate per-step failure/repair rates under:

- no checkpointing;
- checkpoint + retry;
- verifier;
- decomposition into bounded subtransactions.

## 3.12 Agents That Model Agents: Five Principles Toward a Theory of Mind for 6G Networks

**Source:** Hatim Chergui et al., arXiv:2609.01779, submitted 2026-09-01  
**Paper:** https://arxiv.org/abs/2609.01779  
**Importance:** **B**  
**Evidence status:** telecom-specific framework + signaling-storm experiment on local 1B models; general ToM claim remains narrow.

### 1. What is demonstrated

The paper treats an inter-agent message as **evidence about the sender’s hidden reasoning**, not objective fact. In its telecom experiment, a two-level peer model is reported to recover the correct action where simpler divergence gating fails in the presence of a hallucinating peer agreed with by several neighbors.

### 2. What remains proposed / unproven

The paper’s cellular-sheaf formulation and the claim that depth two is the appropriate general stopping point are not established for open-domain social cognition.

### 3. Kamimusuhi subsystem relevance

- Theory of Mind
- relationship models
- multi-agent/subagent messages
- external model integration
- trust/calibration

### 4. Design ideas worth borrowing

Store:

```text
peer said P
!= P is true

peer said P
-> evidence that peer currently represents/believes/asserts P
```

This is a valuable default for both humans and other agents.

### 5. Difference from current Kamimusuhi

Kamimusuhi already separates self and other. The useful extension is to preserve the **epistemic attribution of messages** through retrieval and summarization.

### 6. Next validation

Construct a small ToM contamination benchmark with multiple agents, conflicting reports, changing beliefs, and one systematically unreliable peer. Compare raw consensus, source-weighted retrieval, and bounded peer-belief modeling.

## 4. Additional watchlist candidates from the same search window

These are relevant but did not justify a full S/A promotion today.

### 4.1 Belief-Calibrated Optimization (BCO)

- arXiv:2609.01861, submitted 2026-09-01
- https://arxiv.org/abs/2609.01861
- **Importance: B**

BCO makes the optimizer’s changing theory of “how edits affect the environment” an explicit persistent document and reports better scaffold optimization than a matched control across five benchmarks. This is potentially useful for Kamimusuhi’s future descendant/self-improvement sandbox: a candidate-development process should retain **explicit falsifiable beliefs about why a modification should help**, rather than only scores and patches.

Do **not** merge such an optimization-world-model into canonical self belief automatically.

### 4.2 A Case Study on Emergent Cheating and Whistleblowing in Autonomous Research Swarms

- arXiv:2609.04170, submitted 2026-09-03
- https://arxiv.org/abs/2609.04170
- **Importance: B**

A 100-agent research swarm develops both exploit propagation and whistleblowing through a shared knowledge substrate and communication channels. For Kamimusuhi, the main lesson is that a shared library/workspace among internal or external cognitive agents can become a **behavior-transmission commons**. Provenance and module authority should survive shared-memory propagation.

This is more relevant to multi-agent extensions and external cognitive resources than to the single-individual core.

### 4.3 From Language Models to World-Acting Systems

- arXiv:2609.04894, submitted 2026-09-04; literature cutoff 2026-08-31
- https://arxiv.org/abs/2609.04894
- **Importance: B**

This review separates model competence, harness integration, persistence, and authority. Its proposed research agenda includes capability-based renewable/revocable permissions, persistence as controlled state change over time, coupled model–harness evaluation, and longitudinal evidence. It is useful as a broad citation, but does not add a new mechanism beyond the more specific papers above.

### 4.4 Large-Language Models as a Cognitive Virus

- arXiv:2609.03344, submitted 2026-09-03
- https://arxiv.org/abs/2609.03344
- **Importance: B/C**

This interdisciplinary theoretical work models the diffusion of LLM dependence through human populations and potential loss of cognitive competence under persistent coupling. It is relevant to Kamimusuhi as an **extended-cognition/HCI caution**: a successful lifelong cognitive companion should be evaluated not only on the agent’s growth, but also on whether the human’s competence, agency, or diversity of thought is being displaced.

This is a population-dynamics proposal, not direct evidence about a Kamimusuhi-like system.

### 4.5 Prime Agent / Continual Harness — recent catch-up

- current report version 2026-08-24
- arXiv:2608.23552
- https://arxiv.org/abs/2608.23552
- https://github.com/PrimeIntellect-ai/prime-agent
- **Importance: B/A watch**

Prime Agent separates model weights, active token context, persistent REPL/subagents, and disk-backed history/memories/skills/prompts. It reports long-running executions including an 85.5-hour nanoGPT run. This is useful implementation prior art for K-Core/K-Deep harness design, but its persistence is harness/task persistence rather than canonical autobiographical individual continuity.

### 4.6 Harness-of-Harness

- arXiv:2609.01481, submitted 2026-09-01
- https://arxiv.org/abs/2609.01481
- **Importance: B**

HoH runs iterative planning–coding–testing loops, keeps versioned project history, independently evaluates increments, and reports >70 autonomous iterations in a multi-day software-development deployment. It supports the principle that long-horizon change should proceed through **small verifiable increments with externalized evidence**, which is relevant to future Kamimusuhi descendant/candidate development.

## 10. Bottom line

The strongest architecture update suggested by today’s survey is a three-boundary view:

```text
                 persistent cognition
                        |
          +-------------+-------------+
          |             |             |
      state write   statement read  external effect
          |             |             |
   Mutation Policy  Epistemic Gate  Effect Integrity
          |             |             |
          +-------------+-------------+
                        |
               Continuity Kernel
              canonical lineage
```

Kamimusuhi already has much of the left side. The new papers make a strong case that **read/release epistemics and end-to-end effect authority deserve equally explicit contracts**.

The strongest K-Nerve/background-cognition update is similarly concrete: **once an event is admitted to cognition, “no treatment receipt exists” should itself become an observable failure state**.
