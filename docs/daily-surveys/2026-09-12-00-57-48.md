## 3. Executive summary

今回は **有意な新規発見あり**。強い signal は次の6系統だった。

1. **分散認知では global log の順序より causal visibility が重要。** Causal Past Logic (CPL) は asynchronous agent workflow で、ある lifeline の decision が「その時点で因果的に見えていた event」にのみ依存するよう source-level guard と vector-clock monitor を導入し、local monitor と denotational semantics の一致を証明した。Kamimusuhi の distributed K-Edge/K-Core/background worker では、`event exists somewhere != event was causally knowable here` を first-class に扱う価値が高い。
2. **交換可能な organ 間の latent protocol は、意味が似ていてもそのまま portable とは限らない。** Portable Semantics, Private Dialects では independently trained society 間の cross-initialization 26方向が frozen alignment ladder 全てで zero-shot transfer に失敗し、ある条件では inherited interface を捨てて reader/writer/mouth だけ再初期化すると accuracy が 0.169→0.857 に上がった。Kamimusuhi の organ replacement は model weights だけでなく **inter-organ protocol migration** を評価すべき。
3. **ALife の resource budget は単なるコスト上限ではなく、社会・進化圧そのものになり得る。** Tapes Together Strong は Z80 machine-code organism で computation / replication / social dilemma の cost を同一 substrate に埋め込み、resource scarcity 下で stealing が共有 energy を破壊して自身の replication も損ねるため、cooperation が self-organizing scaffold になり得ることを示した。Kamimusuhi の Cognitive Budget / metabolism を「請求上限」だけでなく behavior-shaping ecology として試す余地がある。
4. **idle/default cognition は、task を知らない段階でも将来の solver cost を下げられる場合があるが、compute を増やせば良いわけではない。** Studying Without a Syllabus は downstream task distribution を知らない pre-task study を形式化し、meta-agent が6 benchmark中5つで Avg@3 最良、study artifact により test-time sampling を減らした一方、larger study budget は reward を一貫して改善しなかった。
5. **身体行動では memory・prediction・action を「実現可能な transition」で結ぶ必要がある。** UniMPA は visually plausible future と physically realizable transition の差を明示し、persistent task-progress latent、visual-action memory、action prototype adaptation を shared transition interface に統合する。Kamimusuhi の embodied memory でも `remembered action != executable now` を明示できる。
6. **K-Nerve は固定 reflex と learned modulation の hybrid を比較対象にすべき。** Reflex-Informed Neuromuscular RL は fixed phase-dependent reflex controller を土台に、RL が4つの解釈可能な residual gain/threshold だけを調整する。nominal condition の歩容品質だけでなく muscle weakness / external perturbation に retraining なしで robustness を報告した。ReactHuman と合わせ、fast substrate を end-to-end neural policy 一択にしない根拠になる。

その次に、agent workflow の `ready != release` を分離して p95 flow time 最大3.50×を報告した tail-aware scheduler、capability gap discovery→task generation→artifact verification→episodic/procedural/semantic consolidation を OSS 化した SimSkill、human-AI live experiment を auditable YAML graph と high-resolution traces で再現する Pairit、probabilistic analog in-memory computing の transaction-level model で GPU 比1000×超を主張する hardware study を収録した。

## 4.1 Causal Past Logic — distributed cognition は「何が記録済みか」より「何が因果的に見えていたか」

**Source:** Benedikt Bollig, *Causal Past Logic for Runtime Verification of Distributed LLM Agent Workflows*, arXiv:2605.20923, v2 2026-09-10, ICFEM 2026 camera-ready  
**Primary:** https://arxiv.org/abs/2605.20923  
**Project:** https://zippergen.io/  
**Importance:** **A+**

### (1) 何が実証済みか

asynchronous distributed agent workflow では、global log 上で先に存在する event でも、ある participant/lifeline にまだ delivery されていなければその decision の根拠にはできない。この問題に対し、CPL は `previous` / `since` に加えて「別 lifeline の latest causally visible event / variable」を参照できる guard を導入する。

vector-clock / knowledge-vector ベースの online monitor を ZipperGen に組み込み、**local に計算した monitor value が current event における denotational semantics と一致する**ことを証明している。v2 は implementation / preliminary evaluation を拡張した camera-ready revision。

### (2) 提案・推測段階

- canonical identity commit / split-brain resolution 自体を解決する研究ではない。
- network partitions、Byzantine process、clock tampering、durable storage failure まで扱うわけではない。
- Kamimusuhi の全 control flow を temporal logic で記述すべきという証拠ではない。

### (3) Kamimusuhi 関連

- Continuity Kernel
- distributed K-Edge / K-Core / K-Deep
- background cognition
- proposal freshness / predecessor validation
- effect finalization
- scheduler / multi-organ workflows

### (4) 借りられる設計

`observed_at` だけでなく causal visibility receipt を持つ。

```text
CausalView
  lifeline_id
  local_event_id
  vector_clock
  visible_heads {source -> event_id}
  authority_epoch
  decision_guard
  evaluated_at
```

特に以下を区別する。

```text
event committed somewhere
!= event delivered here
!= event causally visible to this decision
!= event authorized for this effect
```

### (5) Kamimusuhiとの差分

現行 Kamimusuhi は predecessor / authority / freshness / atomic activation を重視しているが、**各 distributed organ が decision 時にどのremote eventまで知り得たか**の形式的表現は薄い。CPL は continuity conflict の前段にある「partial causal knowledge」を埋める。

### (6) 次に検証

`CausalVisibilityBench`:

- delayed revocation
- delayed relationship update
- stale cached capability
- out-of-order background result
- network partition 後の conflicting proposal

を注入し、wall-clock ordered log / Lamport clock / vector-clock view / CPL-like guard を比較する。metric は unauthorized/stale decision rate、false block、metadata overhead、guard latency。

### (7) 重要度

**A+** — distributed identity continuity の「state が存在する」と「その organ が知ってよい/知っていた」を分離できる。

## 4.2 Portable Semantics, Private Dialects — organ swap では protocol state も migration 対象

**Source:** Narcis Marincat, *Portable Semantics, Private Dialects: Reuse and Negative Transfer in Latent Communication Between Language-Model Cells*, arXiv:2609.11365, 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11365  
**Importance:** **A+**

### (1) 何が実証済みか

shared-genome language-model societies の latent packet communication を調べた companion study。6 independently trained restricted societies の全30 ordered pairsを leakage-controlled audit した結果、semantic role が似るにもかかわらず raw packet language は共通ではなかった。

- same-initialization 1 pair は双方向 interoperable。
- 別の1 pair は asymmetric partial compatibility。
- **26 cross-initialization directions は raw / orthogonal / linear / nonlinear frozen alignment の全段で strict zero-shot transfer に失敗**。
- ある matched adaptation 条件では、globally trained communication interface を継承すると severe negative transfer が起き、**packet reader / writer / mouth のみ再初期化すると depth-three accuracy 0.169→0.857**。
- restricted checkpoints では inherited interface が fresh-interface control を preregistered 0.10 margin 以上で上回らなかった。

### (2) 提案・推測段階

- near-transfer 17-state setting に限定される。
- text/tool/sensor protocol を持つ実 agent deployment で同じ transfer failure が出るとは未証明。
- one study だけで「latent communication は使うべきでない」とは言えない。

### (3) Kamimusuhi 関連

- Persona Core migration
- K-Edge/K-Core inter-organ communication
- external/local specialist model replacement
- latent/non-linguistic K-Nerve interfaces
- model lineage / continuity tests

### (4) 借りられる設計

component migration を weights / benchmark score だけで済ませず、**cognitive ABI compatibility** を独立測定する。

```text
OrganInterfaceReceipt
  producer_model_lineage
  consumer_model_lineage
  protocol_version
  encoder_state_digest
  decoder_state_digest
  alignment_method
  compatibility_suite
  zero_shot_score
  adaptation_score
```

migration strategy も比較する。

- old interface freeze
- full inherit
- adapter alignment
- interface-only reset/retrain
- typed symbolic fallback

### (5) Kamimusuhiとの差分

Kamimusuhi は「model replacement != new identity」を前提にするが、replaceable organs が**独自 dialect を学習している場合、identity state は保持できても cognition の接続性は壊れる**。continuous identity と interface compatibility を別 invariants として評価する必要がある。

### (6) 次に検証

`CognitiveABIMigrationBench`:

- same model different seed
- same family different checkpoint
- different model family
- quantized replacement
- K-Edge↔K-Core pair swap

で latent packet / structured JSON / typed action/event protocol を比較。zero-shot interoperability、retraining samples、negative-transfer rate、recovery timeを測る。

### (7) 重要度

**A+** — Kamimusuhi の中心命題「器官を交換しても同じ個体」を、通信 protocol の観点から直接 stress-test する。

## 4.3 Tapes Together Strong — computation budget を「代謝」として環境に埋め込む

**Source:** Kunal Jha et al., *Tapes Together Strong: The Co-evolution of Computation and Cooperation*, arXiv:2609.10817, submitted 2026-09-09  
**Primary:** https://arxiv.org/abs/2609.10817  
**Importance:** **A+**

### (1) 何が実証済みか

Autopoietic Game Theory として、social interaction、replication mechanism、computation cost を同じ substrate で内生的に共進化させる model を提案。randomly initialized Z80 machine-code programs を進化させる。

resource scarcity 下では stealing が shared energy を破壊し execution を遅くし、reliable replication を阻害するため defection が self-limiting になり得る。複数 Z80 environment で evolved programs が stealing を抑え、spatial assortment が structural complexity / task performance を支えることを報告。math task の reward を computation budget に結び付ける外圧も導入可能とする。

### (2) 提案・推測段階

- Z80 digital organism ecology から persistent language agent の社会へ直接一般化できない。
- cooperation が「人格的価値」として学習されたわけではない。
- Kamimusuhi に scarcity を人工的に課せば望ましい性質が自動的に生える保証はない。

### (3) Kamimusuhi 関連

- Artificial Life / MIOBA direction
- Cognitive Budget
- compute/energy/metabolism
- open-ended evolution
- multi-agent ecology
- self-maintenance / resource regulation

### (4) 借りられる設計

Cognitive Budget を単なる scheduler metadata ではなく、一部実験では**行為の物理的/計算的 consequence**へ結び付ける。

```text
compute action
  -> consumes bounded energy/credit
  -> changes future compute capacity
  -> affects replication/survival/task opportunity
  -> creates endogenous pressure on strategy
```

### (5) Kamimusuhiとの差分

Kamimusuhi は「一個体のcontinuity」が中心で、self-replication や population evolution を normative goal にしていない。したがって借りるべきは生命比喩そのものではなく、**resource dynamics を behavior の外側の請求計算にしない**という実験原理。

### (6) 次に検証

`MetabolicCognitiveBudgetBench`:

- fixed budget
- replenishing budget
- compute-cost tied to environment reward
- shared-resource multi-agent condition

を比較し、spontaneous activity、resource hoarding、cooperation、degraded-mode behavior、goal persistence、pathological self-preservation を測る。identity/persona mutationとは分離する。

### (7) 重要度

**A+** — OpenLife の budget metabolism を、より原理的な digital-organism substrate から補強する新しい比較対象。

## 4.4 Studying Without a Syllabus — task 未知でも preparatory cognition は有用になり得る

**Primary:** https://arxiv.org/abs/2609.10824

## 4.5 UniMPA — memory は「過去に成功した action」ではなく実現可能な transition の証拠

**Source:** Wei Li et al., *UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling*, arXiv:2609.11875, 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11875  
**Project:** https://JiuTian-VL.github.io/UniMPA-page/  
**Importance:** **A**

### (1) 何が実証済みか

VLA manipulation で以下3 gapを明示する。

1. visually similar observation でも manipulation phase が違えば次 transition が異なる。
2. plausible predicted future image が physically executable とは限らない。
3. historically executable action pattern が current scene でも目的 transition を実現するとは限らない。

これに対し、persistent latent stream で task-level progress を追跡し、transition-critical pixel prediction、Temporal Visual-Action Memory Bank、Action-Visual Memory Bank と prototype-biased flow を shared action-grounded transition interface に統合する。

### (2) 提案・推測段階

- paper は robotics manipulation 専用で、general cognitive memory の優位性は示さない。
- canonical autobiographical memory / identity continuity とは別問題。
- benchmark/generalization の詳細は今後 independent replication が必要。

### (3) Kamimusuhi 関連

- embodied episodic/procedural memory
- sensory Event Bus
- K-Edge/K-Nerve
- action prediction
- robot control / physical grounding

### (4) 借りられる設計

`past success` をそのまま skill recall せず、transition contractを挟む。

```text
current state + phase
  -> intended next transition
  -> retrieve historically realized transition
  -> executability check
  -> adapt action prototype to current geometry/state
```

### (5) Kamimusuhiとの差分

Kamimusuhi は canonical event / procedural memory を分けるが、physical skill reuse 時の **transition realizability** はまだ一般 contract として弱い。UniMPA は「記憶にあるから実行可能」を否定する具体例。

### (6) 次に検証

`EmbodiedTransitionMemoryBench`:

- nearest-action recall
- phase-aware recall
- predicted-future only
- action-grounded transition retrieval

を scene perturbation / object relocation / actuator degradation 下で比較。success、unsafe transition、adaptation cost、latencyを測る。

### (7) 重要度

**A** — physical embodiment で memory→action 間に置くべき validation layer を具体化する。

## 4.6 Reflex-Informed Neuromuscular RL — fixed reflex + learned residual modulation

**Source:** Jian Zhou et al., *Reflex-Informed Neuromuscular Reinforcement Learning for Muscle-Driven Locomotion*, arXiv:2609.11733, 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11733  
**Importance:** **A-**

### (1) 何が実証済みか

fixed phase-dependent reflex controller を underlying control mechanism とし、RL policy は hip swing / knee support / ankle propulsion に関する **4つの biomechanically meaningful residual parameters**（gain/threshold）だけを state に応じて調整する。

nominal walking で kinematic accuracy / dynamic consistency / bilateral symmetry / stride-to-stride consistency を改善し、muscle weakness と external perturbation 下でも retraining なしの robustness を報告。

### (2) 提案・推測段階

- humanoid locomotion と Kamimusuhi の cognitive reflex は異なる。
- fixed reflex の安全性が learned modulation によって常に保たれる保証はない。
- latency/energy が K-Nerve 候補として十分低いかは別途測定が必要。

### (3) Kamimusuhi 関連

- K-Nerve
- low-latency control
- learned reflex modulation
- robotics / actuator control
- degraded-mode behavior

### (4) 借りられる設計

end-to-end learned reflex と deterministic rule の二択にしない。

```text
stable reflex substrate
  + small bounded learned residual
  + interpretable modulation range
  + hard invariant clamp
```

### (5) Kamimusuhiとの差分

K-Nerve watchlist は rules / SNN / LUT / tiny model 等を横並びにしている。本研究は **固定回路を捨てずに learned adaptability だけ上乗せする hybrid** を強い候補にする。

### (6) 次に検証

`BoundedResidualReflexBench`:

- fixed FSM/rules
- end-to-end tiny neural policy
- fixed reflex + learned residual
- SNN + bounded residual

を sensor drift / delayed packet / partial actuator failure で比較。safety invariant violation、recovery、latency、energy、interpretabilityを測る。

### (7) 重要度

**A-** — ReactHuman で見えた scale-insensitive physical reaction failure に対する具体的 substrate design candidate。

## 4.7 Decoupling Readiness from Release — `ready != should run now`

**Source:** Bochao Feng et al., *Decoupling Readiness from Release for Tail-Aware Scheduling of Agentic LLM Workflows*, arXiv:2609.10964, 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.10964  
**Importance:** **A-**

### (1) 何が実証済みか

agent workflow では model turn / tool interaction が ready になった瞬間に eager release すると contention 下で released-but-unfinished work が蓄積し、workflow-level policy が後から reorder できなくなる問題を扱う。

mean-CVaR tail-risk objective、online work estimate、queue pressure に応じた released-work budgetを用い、real software-engineering agent traces × multiple LLMs / arrival ratesで評価。light loadでは eager と同程度、contention 下で **workflow P95 flow time 最大3.50× speedup** を報告。

### (2) 提案・推測段階

- software-engineering trace の scheduling result であり、interactive speech/reflexにはそのまま適用不可。
- quality / semantic priority / authority urgency をCVaR latencyだけで表せない。

### (3) Kamimusuhi 関連

- Cognitive Budget scheduler
- K-Core/K-Deep
- background cognition
- tool/model orchestration
- sleep batch workload

### (4) 借りられる設計

`READY` と `RELEASED` を state machine で分ける。

```text
blocked -> ready -> admitted/released -> running -> done
```

さらに `released_work_budget` を tier / user-facing deadline / energy / cost と結び付ける。

### (5) Kamimusuhiとの差分

Kamimusuhi は resource health / budget を routing factor に持つが、**ready task の admission control** はまだ明示的でない。background jobをready順に全投げするとtail latencyを悪化させ得る。

### (6) 次に検証

`CognitiveReleaseSchedulerBench`:

- eager FIFO
- priority
- shortest-estimated-work
- CVaR-like tail-aware
- interactive-reserved hybrid

で p50/p95 response latency、background completion、starvation、GPU utilization、costを測る。

### (7) 重要度

**A-** — 分散認知を「たくさん並列化する」だけでなく admission/release policy として設計する材料。

## 4.8 SimSkill — backbone を変えずに capability gap を自己探索し、検証済み competence を蓄積

**Source:** Qi Liu et al., *SimSkill: A Lifelong Learning AI Agent for Autonomous Mastery of Traffic Simulation*, arXiv:2609.03753  
**Primary:** https://arxiv.org/abs/2609.03753  
**Code:** https://github.com/qiliuchn/SimSkill-V1  
**Importance:** **A**

### (1) 何が実証済みか

SUMO traffic simulation で、agent が capability gap を見つけ、environment-grounded task を生成し、action-agent が解き、critic-agent が artifact を検証し、episodic / procedural / semantic memoryへ consolidationする。backbone weights は更新しない。

repo は raw materials、source付き semantic page、procedural skill、episodic log、append-only change log、memory-lint を分離している。

### (2) 提案・推測段階

- traffic simulation domain から general personal agent へ transfer は未証明。
- autonomous curriculum が identity/persona development に適切とは限らない。

### (3) Kamimusuhi 関連

- self-development sandbox
- procedural/semantic/episodic memory
- default cognition / curiosity
- artifact verification
- skill evolution

### (4) 借りられる設計

特に有用なのは `learn` と `infer` を分け、**test/inference mode では memory mutation を禁止できる**点と、memory typeを跨ぐ append-only change log / lint。

### (5) Kamimusuhiとの差分

Kamimusuhi は canonical evidence / continuity / identity mutation がより厳しい。SimSkill の memory-ingest をそのまま self/persona mutationへ昇格させず、procedural/semantic sandboxとして借りる。

### (6) 次に検証

`AutonomousSkillAcquisitionBench`:

- fixed human curriculum
- novelty-driven curriculum
- failure-gap curriculum
- SimSkill-like curriculum+critic

を tool sandbox で回し、verified skill gain、negative transfer、memory bloat、lint catch rate、costを測る。

### (7) 重要度

**A** — OSS で実装構造と failure/negative resultまで確認できる self-development baseline。

## 4.10 Probabilistic in-memory computing Part 1/2 — uncertainty substrate と memory-compute co-location

**Sources:** Thomas Dalgaty et al.  
- *Bio-inspired Learning and Decision-Making with Probabilistic In-Memory Computing Hardware: Part 1*, arXiv:2609.11281  
- *... Part 2*, arXiv:2609.11288, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11281 / https://arxiv.org/abs/2609.11288  
**Importance:** **B+**

### (1) 何が実証済みか

Part 1 は stochastic neural/synaptic dynamicsを Langevin sampling として使い、latent state / weights の uncertainty を energy-based modelで表す bio-inspired frameworkを提示する。

Part 2 は GPU/HBM で low-arithmetic-intensity massively parallel sampling を行う際の latency bottleneck を指摘し、**probabilistic analogue in-memory computing processor の detailed transaction-level model (TLM)** 上で同じ energy-based model が data-center hardware より1000×超高速になり得ると報告する。

### (2) 提案・推測段階

最重要 caveat は、1000×超が **fabricated silicon の実測ではなく TLM simulation** であること。precision、device variability、end-to-end I/O、training quality、energy measurement、manufacturability は別検証が必要。

### (3) Kamimusuhi 関連

- K-Nerve / low-latency cognition
- probabilistic uncertainty processing
- predictive coding research
- neuromorphic / in-memory hardware
- always-on local cognition

### (4) 借りられる設計

今すぐ architecture requirement にせず、K-Nerve hardware watchlistで次を追う。

- state uncertainty を deterministic scalar confidenceだけでなく sampling dynamicsで表す価値
- memory-compute co-location
- parallel low-arithmetic-intensity controller workload

### (5) Kamimusuhiとの差分

Kamimusuhi は commodity GPU/CPU/FPGAから始める。AIMC は将来 substrate候補であり、identity/memory authorityを hardware dynamicsへ移す必要はない。

### (6) 次に検証

silicon measurement / FPGA emulation / energy per decision / latency distribution / uncertainty calibration / noise robustness が公開されるまで watch。software baselineとして Langevin sampler と tiny probabilistic controller を小規模 K-Nerve taskで比較する。

### (7) 重要度

**B+** — 今すぐ採用ではないが、SNN/LUT/logic-gate以外の「不確実性を物理 noise で計算する」substrate候補として価値がある。

# 10. 結論

今回の差分を短くまとめると、次の5つが重要。

```text
state exists somewhere
!= state was causally visible to this organ

same semantics
!= same interoperable protocol

compute budget
!= mere accounting limit

remembered successful action
!= executable transition now

job is ready
!= job should be released now
```

Kamimusuhi はすでに state / authority / evidence / effect の分離を強く持っている。今回の新規性は、それを **distributed causal knowledge、inter-organ protocol migration、resource ecology、embodied transition realizability、runtime admission control** にまで押し広げられる点にある。

特に `CognitiveABIMigrationBench` と `CausalVisibilityBench` は、既存の model-upgrade memory portability / lease-fencing / transactional continuity と直接結合でき、Kamimusuhi固有の研究価値が高い。次の反映判断では、この2本を優先して architecture requirement ではなく **falsifiable benchmark** として先に実装するのが妥当である。
