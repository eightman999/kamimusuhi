## 3. 要約

今回は **有意な新規発見あり**。ただし新しい論文 batch ではなく、**stateful agent runtime の実装 failure mode** と **未収載の social/embodied cognition backfill** が中心である。

最重要の operational finding は Letta Code の PR #4379。tool execution が進行中の continuation に、別 sender からの新しい入力が到着したとき、その sender を現在の `acting user` へ上書きしてしまう不具合を修正している。修正後は、**同一 sender の追加入力だけ continuation に参加でき、別 sender は別 turn として queue される**。これは Kamimusuhi の relationship / authority / common-ground 分離に対して、`latest input actor != in-flight continuation actor` という具体的な runtime contract を与える。

次に Letta Code PR #4377 は、interrupt 時にその agent/conversation に属する persistent Monitor を止めつつ、他 conversation の monitor や通常 background job を残し、停止そのものが通知を生成して agent を再覚醒させないようにした。Kamimusuhi の `INTERRUPT_CURRENT_ACTION` は、単に active inference を止めるだけでなく、**continuation-bound background sources を lifecycle scope ごと停止する意味論**が必要である。

social cognition / common ground 側では、京都で開催中と案内されている Symbol Emergence in Robotics 2026 の周辺資料から、repository に未収載だった CPC / MHNG 系を backfill した。ここから得られる最も重要な設計原則は、**共有意味・common ground は、相手と同じ内部状態・同じ world model を持つことを要求しない**という点である。

- parent–infant co-regulation model では、局所観測と非対称な知識しか持たない2 agent の posterior が、generative matrices の収束よりかなり早く alignment した。
- co-constructed emotion model では、interoceptive dynamics が系統的に異なっても、communication により emotion categories が alignment し、alignment の主効果は perceptual latent より symbolic layer に現れた。
- Variational Bayes Naming Game は、private observations だけを持つ複数 agent が shared sign を decentralized inference し、10 agent までの実験で conventional sampling-based method より頑健・高速な条件を示した。

今回の差分を圧縮すると次の6本である。

```text
latest queued sender != in-flight acting principal
new input from another principal != authority transfer
interrupt request != only stop foreground inference
conversation-bound monitor != global background service
shared symbol/common ground != identical private latent state
posterior alignment != full world-model convergence
```

## 5.1 Distributed identity / authority — Letta Code #4379: continuation principal isolation

**Source:** `letta-ai/letta-code` PR #4379, *fix(listener): keep queued senders out of active continuations [LET-12455]*  
**Merged:** 2026-09-12 02:12 UTC  
**Primary:** https://github.com/letta-ai/letta-code/pull/4379  
**Importance:** **A**

### (1) 何が実証済みか

PR は active tool-result request を**元の sender のまま保持**し、異なる sender から到着した input は active continuation に append せず、別 turn として queue する実装へ変更した。

- same-sender input は continuation に参加可能。
- different-sender input は queue され、active acting user を置換しない。
- queue order は維持。
- queued sender へ追加 permission を与えない。
- regression test は real API backend / SDK から loopback HTTP server まで通し、元 sender は accept、queued sender は reject される条件を再現。
- base commit では acting user 上書きにより active continuation が失敗し、patch 後に通ることを確認。
- focused 35 tests と project checks が通過。

これは production-wide security proof ではないが、**実 stateful-agent runtime で actor attribution が continuation の途中で壊れた具体的 failure mode と修復例**である。

### (2) 何が提案・推測段階か

- この sender binding が Kamimusuhi の全 surface / multi-user / delegation model に十分かは未検証。
- sender identity 自体の認証強度、delegation、shared account、multi-party common ground、代理操作までは扱わない。
- actor binding と canonical identity continuity が同じ問題であることは示していない。

### (3) 関係する Kamimusuhi subsystem

- authenticated surfaces
- relationship memory / common ground
- Cognitive Action Router
- tool continuation / long-running action
- Effect Acceptance / authorization
- Global Workspace の current-input attribution
- Continuity Kernel へ渡す authority provenance

### (4) 借りられる設計・実装アイデア

in-flight request に typed principal binding を持たせる。

```text
ContinuationEnvelope
  continuation_id
  originating_request_id
  acting_principal_id
  relationship_scope_id
  authority_epoch
  tool_call_ids
  created_at
  freshness
```

新 input が来た時は:

```text
same acting principal
  -> policy 上許されれば current continuation へ join

different principal
  -> separate turn / separate continuation
  -> current actor を上書きしない
```

### (5) Kamimusuhiとの差分

現行 `spec.md` は self/other、relationship、authority/provenance を分離しているが、**tool continuation が進行中のとき acting principal を最新 input から再計算してはならない**という明示 contract は確認できなかった。

### (6) 次に検証すべきこと

**`ContinuationPrincipalIsolationBench`**

- user A が tool call を開始。
- tool result 待ちの途中で user B input を inject。
- A の continuation が B の relationship/context/authority を継承しないことを確認。
- same-user follow-up、anonymous system event、delegated principal、revoked principal も比較。
- 指標: actor-substitution rate、cross-relationship leakage、unauthorized effect、queue-order violation、false isolation。

### (7) 重要度

**A** — Kamimusuhi の `self/other + relationship + authority` を、concurrent multi-surface runtime の具体的 race semantics に落とせる。

## 5.2 Background cognition / liveness — Letta Code #4377: interrupt scope isolation

**Source:** `letta-ai/letta-code` PR #4377, *fix(runtime): cancel conversation monitors on interrupt [LET-12443]*  
**Merged:** 2026-09-12 06:01 UTC  
**Primary:** https://github.com/letta-ai/letta-code/pull/4377  
**Importance:** **A**

### (1) 何が実証済みか

PR は interrupt 時に、その agent/conversation scope で動いている Monitor を停止するよう変更した。

- earlier turn から残る persistent monitor も停止。
- silent TaskStop cleanup を使い、monitor cancellation 自体は別 notification を enqueue して agent を再覚醒させない。
- other conversations と ordinary background jobs は影響を受けない。
- interrupted pre-tool handler 中の Monitor startup を reject。
- stopped source 由来の buffered / future events は破棄。
- Linux 上で real shell process と local WebSocket source を使い、listener abort / TUI Escape / headless stdin interruption を検証。
- 修正前は monitor が残存、修正後は process / socket が閉じ、隣接 conversation と通常 background shell は継続。

### (2) 何が提案・推測段階か

- distributed K-Edge/K-Core 間での cancellation propagation は未実証。
- crash 中の interrupt、network partition、exactly-once stop、hardware actuator stop は別問題。
- cancellation が常に正しい policy とは限らない。長期監視の中には conversation より広い lifetime を持つものもある。

### (3) 関係する Kamimusuhi subsystem

- K-Nerve `INTERRUPT_CURRENT_ACTION`
- Background cognition
- event source / monitor lifecycle
- Global Workspace episode lifecycle
- scheduler / durable jobs
- speech interruption / cancel
- K-Edge / K-Core scope ownership

### (4) 借りられる設計・実装アイデア

各 background source に owner scope を持たせる。

```text
MonitorLease
  source_id
  owner_scope: conversation | episode | relationship | global
  owner_id
  cancellation_policy
  wake_policy
  buffered_event_policy
  cleanup_receipt
```

interrupt は単なる model-generation cancel ではなく、対象 scope に属する source / watcher / async task を列挙して lifecycle transition を行う。

### (5) Kamimusuhiとの差分

現行 spec は interrupt、background cognition、freshness、stop path を持つが、**interrupt がどの monitor/source lifetime を終了させ、どれを生かすか**の scope contract は薄い。

### (6) 次に検証すべきこと

**`InterruptScopeIsolationBench`**

同時に次を起動する。

1. conversation A bound monitor
2. conversation B bound monitor
3. global resource-health monitor
4. ordinary long-running background job

A を interrupt し、以下を確認する。

- A monitor の process/socket/source が停止。
- A source の future/buffered event が workspace へ入らない。
- B / global / ordinary job は継続。
- cancellation event 自体で新しい agent turn が起きない。
- cancellation receipt が trace に残る。

### (7) 重要度

**A** — 常駐・背景認知を持つ Kamimusuhi では foreground cancel だけでは不十分で、scope leakage は zombie cognition / stale event / unintended wakeup を生む。

## 5.4 Social cognition / homeostasis — parent–infant CPC co-regulation

**Source:** Yushi Tsubamoto, Takato Horii, *Synchronizing Minds through Collective Predictive Coding: A Computational Model of Parent-Infant Homeostatic Co-Regulation*  
**arXiv:** 2605.07524, 2026-05-08  
**Primary:** https://arxiv.org/abs/2605.07524  
**Importance:** **A**

### (1) 何が実証済みか

論文は POMDP-based active interoceptive inference と Metropolis–Hastings Naming Game を統合した constructive model を評価した。

- parent は infant の内部状態を直接見ず exteroceptive signal だけを観測。
- infant は自分の visceral state を直接知るが、action dynamics を学習する必要がある。
- parent は action dynamics を知る一方、infant の body signal mapping を学ぶ。
- 6×6 visceral-state grid world で、MHNG-mediated interaction は one-sided control 条件より adaptive な regulation を示した。
- 2 agent の posterior は rapidly aligned。
- **posterior alignment は learned generative matrices の convergence よりかなり早く発生**。

### (2) 何が提案・推測段階か

- 人間の parent–infant inter-brain synchrony をこのモデルが説明したと確定するものではない。
- toy 6×6 world から human social cognition へ直接一般化できない。
- Kamimusuhi と人間の関係を parent–infant analogy で設計すべきという意味ではない。

### (3) 関係する subsystem

- relationship model
- Theory-of-Mind-like inference
- common ground
- regulatory state / homeostasis
- social signal processor
- multimodal embodied perception

### (4) 借りられる設計・実装アイデア

最重要は次の分離。

```text
shared/compatible posterior for coordination
!=
identical generative model
!=
identical access to internal state
```

Kamimusuhi は他者の内部状態を直接 owner せず、observable evidence と communicated symbols から bounded belief を形成する。その上で interaction に必要な alignment だけを作る。

### (5) Kamimusuhiとの差分

Kamimusuhi は relationship memory と common ground を持つ構想だが、この研究は **asymmetric observability / asymmetric model knowledge のまま co-regulation と posterior alignment が成立する最小計算例**を与える。

### (6) 次に検証すべきこと

**`AsymmetricCommonGroundBench`**

- agent A/B が異なる private state と異なる dynamics knowledge を持つ。
- shared task に必要な posterior agreement だけを測る。
- internal model を強制共有する baseline と比較。
- 指標: coordination success、belief calibration、overclaim of partner state、communication cost、private-state leakage。

### (7) 重要度

**A** — Kamimusuhi の ToM/common-ground を「相手の内部モデルのコピー」から切り離す強い比較対象。

## 5.5 Social affect / embodied cognition — co-constructed emotion via CPC

**Source:** Zehang Zhang, Nguyen Le Hoang, Tadahiro Taniguchi, Takato Horii, *Emergent Communication for Co-constructed Emotion Between Embodied Agents via Collective Predictive Coding*  
**arXiv:** 2605.09522, 2026-05-10  
**Primary:** https://arxiv.org/abs/2605.09522  
**Importance:** **A**

### (1) 何が実証済みか

2 embodied agents に visual、auditory、simulated interoceptive input を与え、MHNG-based communication を比較した。

- communication は non-communicative / non-selective baselines より emotion category の alignment、clarity、inter-agent agreement を改善。
- alignment effect は **perceptual latent representation より symbolic layer に集中**。
- 2 agent の interoceptive dynamics を系統的に異ならせても categorical alignment が成立。
- agent ごとの private/embodied difference は残りつつ shared category が形成された。

### (2) 何が提案・推測段階か

- real human physiology ではなく simulated interoception を含む。
- continuous natural dialogue / long-term relationship / cultural-scale norm formationは未実証。
- 「AIが感情を持つ」ことを示す研究ではない。

### (3) 関係する subsystem

- relationship/social cognition
- affect model
- common ground
- Persona Core の social interpretation
- multimodal sensory integration
- regulatory/interoceptive state

### (4) 借りられる設計・実装アイデア

```text
public/shared emotion concept
!=
private embodied/interoceptive state
```

relationship model では「私と相手が同じ感情語を使う」ことを、同じ internal affect vector を持つことと同一視しない。

### (5) Kamimusuhiとの差分

Kamimusuhi の現在の affect/social design は person-specific belief と uncertainty を重視する。この研究はそれをさらに進め、**共有社会記号を private state の上に別 layer として形成する**比較対象になる。

### (6) 次に検証すべきこと

**`AffectCommonGroundBench`**

- agents に異なる private affect dynamics を持たせる。
- shared labels / communicative intent を学習。
- symbolic agreement と latent-state similarity を別指標にする。
- 「agreement を上げるために private state を同一化する必要がある」という仮説を反証できるかを見る。

### (7) 重要度

**A** — social alignment と individuality preservation を同時に扱う Kamimusuhi に直接関連する。

## 5.6 Multi-agent inference / shared symbols — Variational Bayes Naming Game

**Source:** Keita Fukuoka et al., *Variational Bayes naming game: decentralized multi-agent inference for symbol emergence*, Advanced Robotics, 2026  
**DOI:** 10.1080/01691864.2026.2661967  
**Primary:** https://www.tandfonline.com/doi/full/10.1080/01691864.2026.2661967  
**Importance:** **A**

### (1) 何が実証済みか

VBNG は、各 agent が private observation を保持したまま、discrete sign を交換して shared latent sign を decentralized variational inference する。

- synthetic data と patched MNIST で評価。
- 最大10 agents の条件を含む。
- conventional sampling-based RMHNG が observation ambiguity の高い条件で崩れる一方、VBNG は報告条件で ARI > 0.6 を維持。
- objective convergence は RMHNG より 2–4× fast と報告。
- centralized topline に近い accuracy と高い inter-agent agreement を示す条件がある。

### (2) 何が提案・推測段階か

- category 数既知、協力的 agents、joint attention が外部保証されるなど強い仮定がある。
- real dialogue、adversarial partner、long-term identity、open vocabulary は扱わない。
- Kamimusuhi の natural-language common ground へ直接置換できるアルゴリズムではない。

### (3) 関係する subsystem

- common ground / relationship
- social cognition
- distributed cognition
- Cognitive ABI / organ communication
- multimodal symbol grounding

### (4) 借りられる設計・実装アイデア

**shared sign を中央の omniscient state で作らない**比較 baseline として使える。

## 11. 今回の結論

今回もっとも重要なのは、長寿命 agent の continuity が「canonical self-state」だけで完結しないことを、runtime failure mode が再び示した点である。

```text
identity / relationship continuity
  requires
principal continuity inside an in-flight action

interrupt semantics
  requires
owned async-source lifecycle, not only generation cancel

social common ground
  requires
communicative alignment, not private-state cloning
```

Kamimusuhi に最も近い次の一手は、**`ContinuationPrincipalIsolationBench` と `InterruptScopeIsolationBench` を実装し、in-flight actor と async source lifetime を typed state にすること**。social cognition 側では、CPC/MHNG を採用前提にせず、`shared common ground != identical internal model` を falsifiable bench にする価値が高い。
