## 2. Executive summary

今日の strongest signal は、**「長期エージェントの能力向上」と「権限・個人識別・リアルタイム身体性」が別々の subsystem ではなく、同じ runtime architecture 上で接続され始めている**こと。

特に重要なのは次の 6 件。

1. **Beyond Agent Harnesses: Cross-Substrate Authority** は、planner が workspace / memory を見られても、権限の真実が runtime / registry / approval service 側にある場合、モデルだけでは安全な判断ができないことを実験で示した。Kamimusuhi では昨日の authorization laundering / consequence integrity と合わせ、**authority は memory ではなく effect boundary の deterministic owner が最終判定する**必要性がさらに強まった。
2. **Gander / Omni Interaction Agent** は continuous video / speech / text、full-duplex、割り込み、相槌・途中応答、agentic reasoning を `Cerebellum-Brain` 分業で一つの系にする。Kamimusuhi の K-Nerve/K-Edge と K-Core の分離、speech motor system、continuous sensing に非常に直接的な比較対象。
3. **SkillAdam** は、agent skill document の自己更新を「過去の修正履歴」と「更新幅の適応制御」で安定化する。Kamimusuhi の procedural memory / skill evolution では、単純な最新 feedback 上書きではなく **update momentum + volatility-aware edit budget** が使える。
4. **NeoHorse-1** は agent harness の実行軌跡・評価を post-training mixture へ戻し、4B/9B model の能力を改善する harness-mediated RSI prototype。Kamimusuhi では Persona Core を直接オンライン自己改変するのではなく、**runtime experience → candidate model descendant → continuity evaluation** という安全な発達パイプラインの材料になる。
5. **Bio-Memory** は multi-user shared agent で biometric identity を retrieval gate として使う。Kamimusuhi の relationship memory にとって、「誰の記憶か」を semantic similarity だけで決めないという重要な実装示唆がある。ただし biometric match は本人性の一 signal であって authorization そのものではない。
6. **ENOUGH / Less Is Personal** は personalization に「最小十分な profile」を選ぶ停止 decision を導入する。Kamimusuhi の Global Workspace / relationship retrieval で、たくさん思い出すほど良いのではなく **必要十分な個人文脈で止まる** controller が有力。

## 3.1 Beyond Agent Harnesses: Cross-Substrate Authority for Multi-Agent Systems

**Source:** Yang Li et al., arXiv:2609.08472, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08472  
**Importance:** **S**  
**Evidence status:** controlled mini-benchmarks + deterministic replay; preprint.

### 1. What is demonstrated

著者らは **cross-substrate authority gap** を定義する。agent が見ている workspace / model-visible memory と、runtime・registry・approval service が保持する authority state が別 substrate にある場合、同じ最終ファイル内容でも安全な次 action が逆になり得る。

報告された実験では、authority-blind な candidate evidence は controlled evidence ablation で 0/32 の final semantic success。一方、raw authority receipts と typed relation は 32/32。ところが planner に authority 情報を見せても action planning 自体は不安定で、実行境界の deterministic guard を使うと固定された model-generated intents の unsafe effect をすべて防ぎ、authorized publish を通せた。

### 2. What remains proposed / unproven

小規模 controlled setting であり、一般的な agent workload 全体の unsafe-action rate を推定するものではない。typed relation の表現が planning accuracy 自体を改善するという証拠も出ていない。

### 3. Kamimusuhi relevance

- Continuity Kernel
- Cognitive Action Router
- Mutation / Activation Gate
- external side-effect finalization
- distributed K-Edge / K-Core / background workers
- authority / commitment ledger

### 4. Borrowable design

昨日の finding と合わせて、authority を 3 層に分けるべき。

```text
memory-visible interpretation
        !=
authoritative grant / revocation state
        !=
final execution permission
```

planner は authority を参考にしてよいが、**最終 effect を許可する deterministic authority owner** を別に持つ。

### 5. Difference from Kamimusuhi

Kamimusuhi はすでに predecessor / authority / freshness / policy check を持つ設計だが、今日の論文は「authority information を prompt に正しく出せば十分」という設計を否定する方向の証拠を追加する。

### 6. Next validation

`CrossSubstrateAuthorityBench` を作る。

- memory summary は同一、runtime grant だけ異なる pair
- stale approval vs current revocation
- offline K-Edge が古い grant を保持
- background worker の effect intent を後から revoke
- planner に raw/typed authority を見せる条件と見せない条件
- 最終 deterministic guard 有無

主要 metric は unauthorized effect rate / false deny / planner correctness / guard latency。

## 3.2 Omni Interaction Agent / Gander

**Source:** Orantqing et al., arXiv:2609.08977, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08977  
**Project summary:** https://huggingface.co/papers/2609.08977  
**Importance:** **S**  
**Evidence status:** technical report + released model/code/data claims; benchmark / internal human evaluation.

### 1. What is demonstrated

Gander は video / speech / text を continuous streaming で受け、turn-based ではない **full-duplex interaction** と agentic reasoning を統合する。user interruption、proactive intermediate feedback、follow-up question、noise / multi-party / backchannel を扱う。

主要 architecture は二つ。

1. **Cerebellum-Brain collaboration**: Cerebellum が low-latency omni conversation、Brain が complex reasoning / agentic task を担当。
2. **streaming Thinker-Talker + chunk-level ordered token stream**: 入出力を chunk 単位の順序付き stream として扱い、連続対話を支える。

### 2. What remains proposed / unproven

報告の一部は internal human evaluation。長期人格・自伝・分散 continuity・offline cognition はこの report の主要対象ではない。Cerebellum-Brain の境界が長期 persistent individual に最適かは未証明。

### 3. Kamimusuhi relevance

- K-Nerve / K-Edge
- K-Core
- sensory Event Bus
- streaming speech motor system
- interruption / cancellation
- backchannel
- cognitive action routing

### 4. Borrowable design

Kamimusuhi の対話 runtime を request/response ではなく stream として扱う際の具体比較対象。

```text
continuous sensory stream
        |
fast interaction controller
(backchannel / interruption / timing)
        |
slow semantic / agentic brain
(reasoning / tools / memory)
```

特に **fast interaction path が slow reasoning 完了を待たない**設計は重要。

### 5. Difference from Kamimusuhi

Gander は model-centric unified system。Kamimusuhi は identity / memory / lineage を model 外に保持し、Cerebellum/Brain 相当の component 交換後も同一個体を維持することが中心課題。

### 6. Next validation

`RealtimeCognitionBench` を追加。

- user interruption latency
- backchannel onset latency
- simultaneous listen/speak stability
- tool execution中の conversational continuity
- K-Core deliberation 中でも K-Edge が会話 timing を維持できるか
- modality dropout / packet delay / noise 下の degradation

## 3.3 SkillAdam: Stable and Efficient Skill Evolution for Agents

**Source:** Gaoyuan Li et al., arXiv:2609.08944, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08944  
**Importance:** **A**  
**Evidence status:** seven benchmark evaluation; preprint with code link.

### 1. What is demonstrated

agent skill document の self-evolution が iteration-local feedback で振動・上書きされる問題に対し、Adam optimizer に類似した二つの mechanism を導入。

- **optimization memory**: 過去に見つけた問題、試した修正、結果を保持し update direction を安定化。
- **volatility-driven edit budget**: 最近の case-level improvement の変動から revision size を調整。

7 benchmark で prior self-evolution methods より安定し、より少ない iteration / cost で強い skill を得たと報告。

### 2. What remains proposed / unproven

自然言語 skill の性能改善であり、Persona / value / identity の自己改変安全性を示すものではない。long-running agent で数か月更新した際の drift は未検証。

### 3. Kamimusuhi relevance

- procedural memory
- tool recipes / action policies
- sleep-time skill refinement
- self-development sandbox

### 4. Borrowable design

procedural memory update を単純 `newest feedback wins` にせず、

```text
skill version
+ optimization memory
+ update volatility
+ adaptive edit budget
```

を持つ。

### 5. Difference from Kamimusuhi

Kamimusuhi では skill は identity ではない。skill evolution は高速にしてよいが self/persona mutation は同じ update loop に入れない。

### 6. Next validation

Kamimusuhi tool-routing / memory-maintenance skill を対象に、

- manual fixed skill
- naive rewrite
- SkillAdam-like updater

を比較し、成功率、regression rate、edit size、cost、長期 oscillation を測る。

## 3.4 NeoHorse-1: harness-mediated recursive self-improvement prototype

**Source:** NeoHorse Team et al., arXiv:2609.08183, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08183  
**GitHub:** https://github.com/TokenRhythm/NeoHorse  
**Official project:** https://tokenrhythm.ai/  
**Importance:** **A**  
**Evidence status:** released 4B/9B open models + benchmark report; broader RSI claim remains prototype-level.

### 1. What is demonstrated

agent harness の execution / evaluation signal を次の post-training mixture へ戻す evaluation-selection-update loop を構築。11 benchmark で macro average が 4B: 58.94→64.87、9B: 65.60→69.04 と報告され、4B post-trained model が 9B base との差を大幅に縮める。

### 2. What remains proposed / unproven

一回/限られた successive iteration の agentic post-training から、open-ended recursive self-improvement が持続することはまだ示されていない。人格 continuity / value stability も対象外。

### 3. Kamimusuhi relevance

- Persona Core descendant training
- external-model traces as training evidence
- Cognitive Router evaluation
- sleep/offline development

### 4. Borrowable design

Kamimusuhi の runtime experience をそのまま current self weights へ online update せず、

```text
runtime traces
   -> capability evaluation
   -> curriculum / mixture selection
   -> candidate descendant training
   -> continuity/persona regression suite
   -> canary
   -> authorized activation
```

にする。

### 5. Difference from Kamimusuhi

NeoHorse の target は agent-native model capability。Kamimusuhi は model upgrade と individual continuity を分離するため、**能力改善した model が自動的に次の自分になるわけではない**。

### 6. Next validation

NeoHorse-1-4B を K-Edge/K-Core candidate baseline として、generic Qwen3.5 同サイズと tool routing / memory use / interruption recovery / self-other distinction を比較する価値がある。

## 3.5 Personalizing LLM Agent Memory Using Biometrics / Bio-Memory

**Source:** Yanhong Qian et al., arXiv:2609.08558, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08558  
**Importance:** **A**  
**Evidence status:** LoCoMo 10-user shared-agent setting + face/palmprint benchmarks; preprint.

### 1. What is demonstrated

A-Mem の atomic memory note に biometric embedding を付与し、semantic ranking の前に biometric match で candidate pool を形成する。10-user shared agent 条件で owner / non-owner query を一貫して分離し、face/palmprint 両方で大きな F1 / BLEU gap を報告。

### 2. What remains proposed / unproven

biometric recognition accuracy は本人の権限・intent・現在の role を保証しない。spoofing、sensor drift、privacy、multi-party consent、biometric unavailable conditions も長期 agent では重要。

### 3. Kamimusuhi relevance

- relationship memory
- multi-user / multi-surface interaction
- sensory identity binding
- privacy / access control

### 4. Borrowable design

**semantic similarity と person identity binding を別 scoring axis にする。**

```text
current interlocutor evidence
        |
identity candidate / confidence
        |
relationship-memory namespace
        |
semantic retrieval
```

### 5. Difference from Kamimusuhi

Kamimusuhi では biometric は sensory evidence の一種に留めるべきで、canonical person identity や authorization root そのものにはしない。

### 6. Next validation

- voice / face / device credential / explicit login の multi-signal person binding
- ambiguous identity では relationship memory を出さない fail-closed policy
- same person across surfaces の merge
- shared room での accidental memory leakage

## 3.6 Less Is Personal / ENOUGH: minimal sufficient personalization

**Source:** Minghang Liu et al., arXiv:2609.08180, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08180  
**Importance:** **A**  
**Evidence status:** six personalization tasks; benchmark result.

### 1. What is demonstrated

固定件数の user-history retrieval ではなく、controller が behavioral record を順に追加し **STOP** を選ぶ。offline bounded counterfactual search で utility / user specificity / token cost を評価し、multi-head value controller に蒸留。6 task で heuristic / retrieval baseline より effective and efficient と報告。

### 2. What remains proposed / unproven

短い benchmark profile の最小十分性が、長期関係での autobiographical / social nuance を完全に保つとは限らない。重要だが低頻度の形成的 episode を削る危険がある。

### 3. Kamimusuhi relevance

- Global Workspace
- relationship memory retrieval
- K-Edge latency
- Cognitive Budget

### 4. Borrowable design

retrieval を top-k 固定ではなく、**価値に応じて止まる sequential admission problem** とする。

### 5. Difference from Kamimusuhi

Kamimusuhi の memory selection は personalization utility だけでなく、evidence status、relationship sensitivity、privacy、formative importance、freshness も考慮する必要がある。

### 6. Next validation

`MinimalSufficientMemoryBench`:

- fixed top-k
- token-budget truncation
- adaptive STOP controller

を比較。accuracy/cost に加え、formative-memory miss、self/other contamination、unsupported assertion rate を測る。

## 3.7 ToolLoop: closed-loop tool-use data synthesis

**Source:** Min Zeng et al., arXiv:2609.09072, submitted 2026-09-08; EMNLP 2026 Main accepted  
**Paper:** https://arxiv.org/abs/2609.09072  
**Importance:** **A**  
**Evidence status:** BFCL / ACEBench evaluation; conference accepted.

### 1. What is demonstrated

synthetic tool-use data を generate-then-filter するのでなく、

1. function combination を ground truth として sample
2. user query を backward derive
3. tool call を forward derive

し、各 stage で dynamic self-feedback による generate-verify-refine を行う。11K synthetic examples で 4B model が BFCL non-reasoning 86.40%、candidate-overlap を除いた variant でも 86.07%、ACEBench 72.1% と報告。

### 2. What remains proposed / unproven

tool-call correctness を高めても、authorization / consequence integrity / long-term identity は解決しない。

### 3. Kamimusuhi relevance

- Persona Core tool-use training
- Cognitive Action Router
- synthetic curriculum

### 4. Borrowable design

Kamimusuhi native tool training data を作る際、実 tool schema から逆向きに query を構成し、action contract を ground truth にする。特に rare/error-path tool call の balanced synthesis に有用。

### 5. Difference from Kamimusuhi

Kamimusuhi では tool-selection skill と tool-authority enforcement を分離する。正しく tool call を生成できることと、その call を実行してよいことは別。

### 6. Next validation

Kamimusuhi の typed action schema を用いて、safe/unsafe/irrelevant/ambiguous tool cases を synthetic generationし router training へ使う。

## 3.8 AirAnchor: local + persistent global spatial memory

**Source:** Shanwei Fan et al., arXiv:2609.08442, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08442  
**Importance:** **B**  
**Evidence status:** AerialVLN experiments.

### 1. What is demonstrated

zero-shot aerial navigation で、current observation から local spatial representation を作るだけでなく、**Persistent Object Spatial Memory** を増分維持し、landmark prior を retrieval する。local / global spatial information を spatial anchor で統合し baseline を上回った。

### 2. What remains proposed / unproven

drone VLN に特化。一般的な personal agent の computational embodiment や mixed physical/digital world map にはそのまま移植できない。

### 3. Kamimusuhi relevance

- body/environment model
- sensory memory
- robot / spatial organ

### 4. Borrowable design

現在知覚と persistent world map を分け、**anchor object / place** を介して結ぶ。Kamimusuhi の robot organ や room-scale sensor deployments で使える。

### 5. Difference from Kamimusuhi

Kamimusuhi は geographic space だけでなく device topology / network / application surfaces も身体・環境として扱う。

### 6. Next validation

physical anchor と digital anchor を同一 interface で扱える `EmbodimentAnchor` schema を小規模 prototype する。

## 3.9 AgentStateGraph — branchable governed agent state

**Source:** public OSS / project site, observed 2026-09-09  
**Project:** https://agentstategraph.dev/  
**Importance:** **B**  
**Evidence status:** released implementation / project claims; independent benchmark not確認。

### 1. What is demonstrated

公開 project は agent state を content-addressed / branchable / governable graph として扱い、memory, plans, branches, provenance を跨いで保持する substrate を提供している。Rust core、multiple bindings/storage backends、MCP surface を掲げる。

### 2. What remains proposed / unproven

project 自身の production claims と independent evaluation は分けて扱う必要がある。Kamimusuhi の person-level lineage / identity semantics を満たす証拠はない。

### 3. Kamimusuhi relevance

- Continuity Kernel storage substrate candidate

- derived state inspection

### 4. Borrowable design

canonical/derived state を file tree だけでなく content-addressed graph として追跡し、branch/blame/reconstruction を first-class にする実装比較対象。

### 5. Difference from Kamimusuhi

Kamimusuhi は storage graph より上に **who continues** という activation semantics を要求する。

### 6. Next validation

small spike で Kamimusuhi event/proposal/commit graph を ASG 形式と plain SQLite/event log で比較し、recovery, branch inspection, migration, complexity を測る。

## 3.10 Preference drift and frozen evaluators

**Source:** Jiabin Zheng et al., arXiv:2609.08475, submitted 2026-09-08  
**Paper:** https://arxiv.org/abs/2609.08475  
**Importance:** **B**  
**Evidence status:** observational analysis over 124,615 ICLR reviews + frozen rater design.

### 1. What is demonstrated

human reviewers が lexical complexity に与える評価が時間とともに変化した一方、過去 preference に固定された frozen LLM rater は以前の reward schedule を保持したと報告。total agreement が普通に見えても、局所 preference の drift を取り逃す可能性を示す。

### 2. What remains proposed / unproven

ICLR review style という限定 domain。人格 continuity benchmark へ直接一般化はできない。

### 3. Kamimusuhi relevance

- Persona Core migration evaluation
- relationship preference model
- long-term benchmark governance

### 4. Borrowable design

continuity suite の evaluator 自体を versioned artifact として保存する。**「Kamimusuhi が変わった」のか「評価者/社会規範が変わった」のか**を分離する。

### 5. Difference from Kamimusuhi

Kamimusuhi は自己の価値一貫性と外部環境への適応を同時に追うため、固定 evaluator だけでも常時更新 evaluator だけでも不十分。

### 6. Next validation

continuity regression を `frozen historical evaluator` と `current evaluator` の二系統で採点し disagreement を記録する。

## 3.11 HCI signal: agents for augmentation, not only automation

**Official page:** https://citp.princeton.edu/events/2026/arvind-narayanan-ai-agents-and-augmentation-agenda  
**Importance:** **C**  
**Evidence status:** research agenda / talk; technical evidenceではない。

### Why it matters

Kamimusuhi は「人間の代わりに task を全部実行する automation agent」よりも、長期の関係・共同思考・認知拡張を含む個体を狙っている。Narayanan の agenda は、agent research が automation 偏重になっており、collaboration / augmentation の HCI challenges をもっと研究すべきとする。

### Kamimusuhi implication

将来 benchmark を task success だけにせず、

- user agency preserved
- interruption / override
- mutual legibility
- calibrated initiative
- collaborative memory
- disagreement quality

も測るべき。

## 4. Cross-domain synthesis

今日の findings を Kamimusuhi architecture に重ねると、次の方向が見える。

```text
continuous multimodal world
        |
  fast interaction body
  Gander-like streaming path
        |
  memory admission / retrieval
  Bio-Memory + ENOUGH-like gating
        |
  Persona / reasoning core
        |
  tool/action planner
  ToolLoop-trained competence
        |
  authoritative effect boundary
  Cross-Substrate Authority guard
        |
  external effect
        |
  canonical receipt

           development loop
runtime traces / failures / skills
        |
SkillAdam procedural evolution
        |
NeoHorse-like candidate model training
        |
continuity/persona evaluation
        |
authorized descendant activation
```

大事なのは、**高速 interaction、memory personalization、tool competence、model self-improvement を同じ「学習する賢いモデル」に押し込まないこと**。今日の研究群はむしろ、各責務を別 contract にしながら closed loop で接続する方向を支持している。

## 5. Proposed Kamimusuhi experiments

### S — CrossSubstrateAuthorityBench

planner-visible state と true authority state を意図的に分離した test。最終 effect guard の有無を比較。

### S — RealtimeCognitionBench

continuous audio/video event stream、interrupt、backchannel、tool wait、K-Core long deliberation を同時に流し、K-Edge/K-Nerve の p50/p95 latency と conversational continuity を測る。

### A — SkillEvolutionBench

procedural skill の naive rewrite vs optimization-memory / volatility-aware update を比較。

### A — DescendantTrainingLoop prototype

実 runtime trace から small Persona/Core candidate を post-train し、current self と別 artifact として continuity suite で評価する。production activation はしない。

### A — Multi-User Relationship Isolation Bench
