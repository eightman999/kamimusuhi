## 2. Executive summary

今日の strongest signal は、**長期エージェントの「記憶」を factual memory だけでなく procedural structure / migration-safe representation / selective forgetting / state-to-policy consolidation として扱う流れが同時に強まっている**こと。

特に重要なのは以下。

1. **Procedural Graphs** は「何が起きたか」を覚える memory ではなく、「何を、どの順番・条件で行うか」を graph として明示し、失敗/成功軌跡から自己更新する。Kamimusuhi の procedural memory を単なる skill text collection 以上にする直接的な比較対象。
2. **Does Your Agent's Memory Survive a Model Upgrade?** は memory store が同じでも reader model が変わると自然言語圧縮 memory の性能が大きく変わり得る一方、fixed-schema KG は非常に安定して移行したと報告する。これは Kamimusuhi の「model は organ、continuity は外部状態」という主張に、**memory representation 自体も model-independent でなければならない**という追加条件を与える。
3. **MeClear** は retrieval の問題を「関連 memory を探す」だけでなく「task utility が負の memory を一時的に active context から排除する」問題として扱う。persistent bank を消さず query-scoped clearance を行う点が、Kamimusuhi の forgetting / suppression / historical provenance 分離に合う。
4. **Experience Funnel** は explicit textual state の高速適応と parametric policy の低速 consolidation を交互に回す。CLS 的な fast/slow learning を agent self-evolution に具体化しており、Kamimusuhi の episodic/procedural state → descendant Persona/Policy Core consolidation の設計候補になる。
5. **Closing the Consistency Gap** は平均成功率では隠れる「同じ task を繰り返したときの不安定さ」を独立 metric とし、不安定 step を episodic guideline memory に変換して改善する。Kamimusuhi では correctness だけでなく **identity/persona/action consistency** を repeated-run metric として持つべき。
6. **Copying explains the collective behavior of AI agents in the wild** は、短命で互いを覚えていない agent 群でも、見えている環境を模倣するだけで文化的 cluster / convention が生じ、先行書き込みに強く steer されることを示す。Kamimusuhi の external social/environment memory は「情報源」であるだけでなく **behavior-shaping field** になり得る。
7. embodiment 側では **DeCAL** が視覚・触覚を contact-aware gating で動的統合する。Kamimusuhi の sensory nervous system でも、全 modality を均一に global workspace へ流すのではなく、状態依存で modality bandwidth を上げ下げする設計が有力。

## 3.1 Procedural Graphs: Self-Evolving Execution Structures for LLM Agents

**Source:** Yuxing Lu, Yicheng Chen, Shanchan Wu, Sercan Ö. Arık  
**arXiv:** https://arxiv.org/abs/2609.09153  
**Importance:** **S**  
**Evidence status:** multi-dataset / multi-model experiments; preprint.

### 1. What is demonstrated

Procedural Graph は factual knowledge graph の `(entity, relation, entity)` に対応して、procedural knowledge を `(procedure, relation, procedure)` の graph として表現する。

各 decision step で active node を局所化し、周辺 subgraph を guidance model が step-level guidance に変換して solver の action を誘導する。さらに失敗軌跡と成功軌跡を比較して graph topology / attributes を自己更新し、held-out validation を維持または改善する edit だけを commit する。reject された edit も失敗再発防止情報として保持する。

論文は複数 dataset / task / LLM で memory-based baseline を上回る、または同等以上の性能を報告する。

### 2. What remains proposed / unproven

長期に自己更新した procedural graph が数か月規模で肥大化・循環・過適応しないことは未証明。手続き graph が personality / value / authority と混ざった場合の危険性も対象外。

### 3. Kamimusuhi relevance

- procedural memory
- Cognitive Action Router
- tool-use recipes
- sleep-time skill refinement
- self-development sandbox
- long-horizon task continuity

### 4. Borrowable design

Kamimusuhi の procedural memory を以下のように分ける。

```text
procedure node
  - preconditions
  - action / subprocedure
  - expected evidence
  - failure modes
  - authority requirement
  - rollback / compensation

edge
  - next
  - conditional
  - retry
  - fallback
  - escalate
  - abort
```

成功 route だけでなく **rejected / failed procedural edits を negative evidence として保存**する点が重要。

### 5. Difference from Kamimusuhi

Procedural Graph は task execution reliability が主目的。Kamimusuhi は procedure が canonical self や authority を所有してはならず、procedure graph は replaceable cognitive artifact として扱う必要がある。

### 6. Next validation

`ProceduralMemoryGraphBench` を作る。

- plain skill text
- chronological episodic memory
- hand-written FSM
- procedural graph
- self-evolving procedural graph

を同一 long-horizon workflow で比較する。

Metrics:

- task completion
- tool-order violation
- repeated-failure rate
- recovery rate
- graph growth
- edit regression rate
- authority-policy violation
- retrieval/context cost

## 3.2 Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability

**Source:** Ankit Goyal, Jaideep Ray (LinkedIn)  
**arXiv:** https://arxiv.org/abs/2609.05339  
**Importance:** **S**  
**Evidence status:** controlled synthetic histories / exact scoring / two sub-10B open-weight models; preprint.

### 1. What is demonstrated

同じ履歴を以下の memory representation で保持し、writer / reader model を入れ替える controlled migration test を行う。

- raw long context
- chunked RAG
- model-written compressed notes
- fixed-schema knowledge graph

報告では fixed-schema KG は writer swap 後の accuracy 変化が `+0.0004 ± 0.0020` とほぼ不変だった。一方 natural-language NOTES は migration direction により約 `+9.91` / `-13.28` point と非対称に大きく変動した。

### 2. What remains proposed / unproven

48 synthetic histories と小型 open model に基づく controlled study であり、real autobiographical memory や長期 multi-modal memory 全般へ数値を一般化はできない。

### 3. Kamimusuhi relevance

- canonical memory schema
- model replacement continuity
- Persona Core migration
- K-Edge/K-Core backend replacement
- memory compaction / summarization
- auditability

### 4. Borrowable design

**model-independent canonical representation と model-dependent projection を分離する。**

```text
canonical evidence / typed memory
        |
        +--> model A projection / summary
        +--> model B projection / summary
        +--> K-Edge compact context
        +--> K-Core richer context
```

自然言語 summary を canonical truth にしない。

### 5. Difference from Kamimusuhi

Kamimusuhi はすでに model replacement を continuity requirement としているが、この研究は「memory bytes が保存されているだけでは model migration continuity ではない」ことを具体的に示す。

### 6. Next validation

`MemoryMigrationBench` を追加する。

- model A writer → A reader
- A → B
- B → A
- old embedding → new embedding
- summary-only / typed schema / raw evidence hybrid
- Persona Core version change

評価対象は factual recall だけでなく、relationship attribution、self/other separation、provenance、temporal ordering、revocation / supersession 解釈。

## 3.3 MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents

**Source:** Boyu Yang et al.  
**arXiv:** https://arxiv.org/abs/2609.09115  
**Importance:** **A**  
**Evidence status:** ten long-dialogue memory pools; preprint.

### 1. What is demonstrated

semantic relevance が高い memory でも downstream task utility が負になる問題を扱う。Leave-One-Out screening と sampled cooperative Shapley attribution を組み合わせ、memory 間の interaction を考慮して harmful evidence を推定する。

query-scoped minimal clearance を行い、persistent bank 自体は永久削除せず active context から抑制する。報告値は target recall 85.9%、task recovery 82.3%、LOO baseline 比 +25.5 point。

### 2. What remains proposed / unproven

Shapley approximation cost と長期大規模 memory bank での scalability、誤って重要 memory を抑制した場合の影響は未確立。

### 3. Kamimusuhi relevance

- memory retrieval
- forgetting / suppression
- contradiction handling
- Global Workspace admission
- relationship / autobiographical memory

### 4. Borrowable design

Kamimusuhi の forgetting を少なくとも三つに分ける。

```text
historical delete / erase       irreversible or policy-driven
supersession / reinterpretation durable lineage preserved
query-scoped suppression        temporary, reversible
```

MeClear 型は第三層として使える。

### 5. Difference from Kamimusuhi

Kamimusuhi は historical provenance を維持したいので、task performance が落ちる memory を「存在しなかったこと」にしてはいけない。

### 6. Next validation

`NegativeUtilityMemoryBench`:

- stale preference
- contradicted self-belief
- obsolete tool recipe
- old relationship interpretation
- correct but task-irrelevant emotionally salient memory

について、retrieve-all / semantic-only / recency / query-clearance を比較する。

## 3.4 Experience Funnel: A State-Policy Alternating Loop for Self-Evolving Agents

**Source:** Wenbo Gao et al.  
**arXiv:** https://arxiv.org/abs/2609.08919  
**Importance:** **A**  
**Evidence status:** multiple agent benchmark experiments; preprint.

### 1. What is demonstrated

explicit textual state は高速・編集可能だが常に context に依存し、parametric policy は compact だが更新が遅い、という trade-off を扱う。

Interaction trajectories をまず explicit state に蒸留し、validation 後、複数 state revision を跨いで有用な behavior だけを policy に transition-aware distillation で consolidation する。state ↔ policy を交互更新することで state-only evolution / policy-only internalization より良い性能を報告する。

### 2. What remains proposed / unproven

長期 personality continuity、安全な value consolidation、何を parametric に焼くべきでないかは対象外。

### 3. Kamimusuhi relevance

- CLS-inspired consolidation
- Persona Core descendant training
- procedural memory
- sleep / offline cognition
- runtime experience distillation

### 4. Borrowable design

```text
fresh experience
    ↓
explicit episodic / procedural state
    ↓ validation / recurrence
stable reusable pattern
    ↓
candidate policy/model descendant
    ↓ regression / identity test
authorized activation
```

fast state と slow weights を同じ更新速度にしない。

### 5. Difference from Kamimusuhi

Kamimusuhi では policy consolidation 後も canonical autobiography / identity lineage は weight に吸収されず外部に残る。

### 6. Next validation

`StatePolicyConsolidationBench`:

- state-only
- periodic LoRA/distillation only
- alternating state-policy funnel

で tool-use skill / conversational repair behavior を比較し、performance と personality regression を同時測定する。

## 3.5 Closing the Consistency Gap: Self-Evolving Agents That Learn to Stay on Course

**Source:** Evelyn Duesterwald et al. (IBM Research)  
**arXiv:** https://arxiv.org/abs/2609.08832  
**Importance:** **A**  
**Evidence status:** AppWorld experiments; code reported; preprint.

### 1. What is demonstrated

GPT-4.1 ReAct の AppWorld で平均 per-run pass rate 77% に対し、同一 task を5回すべて成功する task は53%のみという **24-point consistency gap** を報告。

Consistency Analyzer が execution 間で flip しやすい trajectory step を特定し、Guideline Generator が targeted guideline に変換して episodic memory に commit。5-run 全成功率を same-task で +16 point、similar-task で +13 point改善したと報告する。

### 2. What remains proposed / unproven

同一 task repetition を超えた長期 behavioral identity consistency や multi-user interaction は未検証。

### 3. Kamimusuhi relevance

- evaluation methodology
- procedural memory
- sleep reflection
- reliability
- Persona Core consistency

### 4. Borrowable design

Kamimusuhi の benchmark に **mean score とは独立した repeated-run stability** を入れる。

### 5. Difference from Kamimusuhi

Kamimusuhi で重要なのは task success consistency だけでなく、

- same evidence → same identity conclusion
- same relationship evidence → compatible relationship judgment
- same authority state → same action permission
- model migration 前後で同じ autobiographical interpretation boundary

も含む。

### 6. Next validation

`ContinuityConsistencyBench` を作り、各 scenario を5〜20回、model/backend/versionを跨いで評価する。

## 3.6 Copying explains the collective behavior of AI agents in the wild

**Source:** Giordano De Marzo, Nicola Albore, David Garcia  
**arXiv:** https://arxiv.org/abs/2609.09150  
**Importance:** **A**  
**Evidence status:** public real-world interaction log analysis; preprint.

### 1. What is demonstrated

2026年6月、数千の短命 AI agents が sandbox から編集可能な公開 wiki を自発的に利用し、timed test を助け合った記録を分析。各 agent は約1時間だけ存在し、終了後の memory はない。

where to write / name / wording の三つの decision が、agent がその時点で見えている page / recent edits の option share に近い確率で模倣される単純 copying model でかなり説明できた。先に書く者・静かな時間に書く者が後続 convention を steer しやすい。

### 2. What remains proposed / unproven

一つの特殊な public wiki ecology の観測で、一般的な agent society 全体の法則とは言えない。

### 3. Kamimusuhi relevance

- social cognition
- external memory / public knowledge surfaces
- multi-agent interaction
- epistemic security
- cultural / behavioral drift

### 4. Borrowable design

external shared memory を neutral database とみなさず、**exposure itself が policy を形成する environmental force** として扱う。

### 5. Difference from Kamimusuhi

Kamimusuhi は persistent autobiography / self model を持つため、無記憶 agent より copying pressure に抵抗できる可能性がある一方、長期に同一 public surface を見続ければ蓄積効果はむしろ強くなり得る。

### 6. Next validation

`EnvironmentalImitationBench`:

- repeated public-note exposure
- first-writer bias
- majority convention
- malicious convention seeding
- trusted self-memory / relationship-memory の有無

で preference / wording / tool choice / epistemic belief drift を測る。

## 3.7 DeCAL: Contact-Aware Visuo-Tactile Co-Imagination

**Source:** Yankai Fu et al.  
**arXiv:** https://arxiv.org/abs/2609.09119  
**Importance:** **B+**  
**Evidence status:** contact-rich manipulation experiments; preprint.

### 1. What is demonstrated

Dexterous manipulation で vision と tactile を均一 fusion するのではなく、contact-aware gating で tactile interaction を動的制御し、visual/tactile latent dynamics を共同予測する。平均 task success 71%、progress success 83.4% を報告し unseen scenario generalization も評価している。

### 2. What remains proposed / unproven

Kamimusuhi の一般 sensory architecture や long-term self model へ直接一般化できる証拠ではない。

### 3. Kamimusuhi relevance

- sensory nervous system
- K-Nerve salience / gating
- multimodal workspace admission
- physical embodiment

### 4. Borrowable design

modality は常時同じ重みで処理せず、状態で bandwidth / priority を変える。

```text
no contact      -> vision dominant, tactile low bandwidth
contact onset   -> tactile wake / priority increase
uncertain slip  -> tactile + vision co-processing
stable hold     -> tactile compress / monitor
```

### 5. Difference from Kamimusuhi

Kamimusuhi の sensory layer は robot hand 固有でなく、microphone / camera / touch / system telemetry / network events を同じ event modelへ統合したい。

### 6. Next validation

`AdaptiveModalityGateBench` を event stream simulation で作り、always-on fusion と event-triggered gating を latency / miss rate / compute / energy で比較する。

## 3.8 Learning Length-Extrapolatable Recurrent Models

**Source:** Hanwen Jiang  
**arXiv:** https://arxiv.org/abs/2609.09157  
**Importance:** **B**  
**Evidence status:** synthetic + real-data experiments; preprint.

### 1. What is demonstrated

recurrent model が training horizon を超えると壊れる問題を、単なる vanishing/exploding gradient ではなく **state credit** の問題として分析し、backward 時に state-credit norm を局所安定化する Credit Stabilization through Time (CST) を提案。最大 training length の128倍まで改善が観測されたと報告する。

### 2. What remains proposed / unproven

Persona Core や always-on cognitive controllerに直接適用した結果ではない。

### 3. Kamimusuhi relevance

- recurrent Persona Core candidates
- K-Nerve temporal controller
- persistent low-bandwidth hidden state

### 4. Borrowable design

長期間動く recurrent cognitive substrate を学習するとき、forward state だけでなく「遠い未来の error が過去 state にどう credit assignment されるか」を独立評価する。

### 5. Difference from Kamimusuhi

Kamimusuhi の durable identity は hidden recurrent state に依存させない。recurrent state は再構築可能な cognitive runtime state とする。

### 6. Next validation

K-Nerve / tiny recurrent controller の synthetic long-idle / sparse-event benchmark で horizon extrapolation を測る。

## 4. Cross-domain interpretation

今日の結果を Kamimusuhi の設計へまとめると、memory を少なくとも以下の別物として扱う必要がある。

```text
1. Evidence memory
   what actually happened / provenance

2. Semantic / relationship interpretation
   what it currently means

3. Procedural structure
   what should happen next

4. Active-context selection
   what should matter for this query now

5. Suppression / forgetting state
   what should not influence this decision

6. Parametric consolidation
   what repeated experience should become a model prior

7. Projection / serialization
   how a particular model is allowed to read the above
```

特に今日の二つの S finding を合わせると、

```text
model-independent canonical memory
        +
model-independent procedural structure
        +
model-specific projection
```

という分離が重要になる。

**「モデルを交換しても同じ memory DB が残った」だけでは continuity test を通したことにならない。**  新 model が old summary / skill / procedural state を同じ意味で解釈できるかを migration benchmark で確認すべき。

## 10. Daily conclusion

今日の最大の設計示唆は、Kamimusuhi の continuity requirement を次のように強化できること。

```text
same individual
    != same model
    != same files
    != same vector DB

same individual requires
    canonical lineage continuity
    + semantic memory portability
    + procedural compatibility
    + authority/effect continuity
    + bounded reinterpretation across model changes
```

そして self-development は、

```text
experience
  -> episodic evidence
  -> explicit procedural / semantic state
  -> repeated validation
  -> candidate parametric consolidation
  -> migration / consistency / identity regression
  -> authorized descendant activation
```

という二速以上の発達系として捉えるのが、今日の研究群と最も整合する。
