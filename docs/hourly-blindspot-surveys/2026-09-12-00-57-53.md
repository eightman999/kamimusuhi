## 3. Executive summary

今回は **有意な新規発見あり**。

最も Kamimusuhi 固有の中心問題に近いのは **Portable Semantics, Private Dialects** である。6つの independently trained restricted society の latent packet interface を全30方向で監査した結果、意味的に似た interface が一つの共有 raw language を形成するわけではなく、cross-initialization の26方向は frozen alignment ladder の全段で失敗した。さらに、ある globally trained interface は後続適応において severe negative-transfer prior となり、packet reader/writer/mouth だけを再初期化すると depth-three accuracy が **0.169 → 0.857** に上がった。Kamimusuhi が Persona Core、K-Edge/K-Core、specialist cell を将来差し替えるなら、**`semantic role compatible != latent protocol compatible`** を明示し、内部通信interfaceにも version / compatibility / adapter / reset policy を持たせる必要がある。重要度 **A+**。

次に **GuardedAct** は、既存の Effect Acceptance と別の穴を埋める。Effect Acceptance は authority / freshness / exact target / replay 等を最終effect直前に確認するが、GuardedAct はその一歩前で candidate remediation を digital-twin sandbox にかけ、blast radius と rollback confidence を評価する。DeathStarBench の5 fault scenario で、direct LLM execution に比べ collateral damage を **25.6% → 5.2%** に減らしつつ overall recovery 87.4%、MTTR は約8秒増加した。Kamimusuhi では **`authorized effect != operationally acceptable consequence`** として `ActionRiskEnvelope` を EffectAcceptanceGate の前段に置く候補を **A+** とした。

身体性では **UniMPA** が重要である。論文は `visually plausible predicted future != physically realizable transition` と `historically executable action != currently executable action` を明示的に扱い、future prediction を過去に実現した visual-action transition で grounding したうえで current scene に適応する。Kamimusuhi の procedural / embodied memory も skill 名や prose だけでなく、**`state_before → action → observed_transition → realization conditions`** を保持する `TransitionMemoryRecord` を検討すべきである。重要度 **A**。

K-Nerve には **Reflex-Informed Neuromuscular RL** が具体的な hybrid pattern を与える。固定 phase-dependent reflex controller を base にし、RL は4つの biomechanically meaningful residual parameter だけを調整する。muscle weakness / external perturbation に再学習なしで頑健性を報告している。ReactHuman が「大きなMLLMだけでは身体反応failureが消えない」と示したのに対し、この研究は **hard/auditable reflex を残し、learned component は bounded residual modulation に制限する**実装パターンを与えるため、差分として **A**。

理論側では **degeneracy** が distributed embodiment の設計語彙として有用だった。redundancy は交換可能な複製、degeneracy は「ある出力については同機能だが、別contextでは異なる振る舞いをする非同一要素」である。Kamimusuhi の resiliency を同じ provider/model/node の複製だけで測らず、audio prosody / ASR timing / vision cue、local model / rule engine / remote specialist のような **異質な isofunctional pathway** の coverage と shared failure domain を測る `FunctionalDegeneracyProfile` を **A-** とした。

また将来の Persona Core weight consolidation に対して、**Predicting Privacy Leakage from Weight Spectral Density** は `DB privacy != weight privacy` を再確認させる。membership inference attack は高価だが、stable rank や Log alpha-Norm のような spectral metric が MIA vulnerability と相関するという初期結果が報告された。これは privacy guarantee ではないため、Kamimusuhi では **cheap pre-screen telemetry** に限定し、actual attack-based audit の代替にはしない。重要度 **B+**。

人工生命側の **Tapes Together Strong** は、social interaction / self-replication / computation cost を同じ computational physics に埋め込むと、resource scarcity 下で stealing が共有energyを破壊して自らの replication も難しくなり、cooperative strategy が進化し得ることを Z80 program ecology で示す。Kamimusuhi へ直接移植はしないが、多数 organ / self-improvement population を回す際に **resource externality を cognition budget に含める**研究仮説として **B+** とした。Artificial Id の「persistence pressure は alignment ではない」という負の原則は維持する。

## 4.1 Portable Semantics, Private Dialects — cognitive cell の意味互換と protocol 互換は別

**Source:** Narcis Marincat, *Portable Semantics, Private Dialects: Reuse and Negative Transfer in Latent Communication Between Language-Model Cells*, arXiv:2609.11365, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11365  
**Importance:** **A+**  
**Blind-spot class:** latent communication / component swap / neural protocol versioning / negative transfer

### (1) 何が実証済みか

6つの independently trained restricted societies について、全30 ordered pair を leakage-controlled に監査し、raw / orthogonal / linear / nonlinear alignment ladder で latent packet interoperability を検証した。

- one same-initialization pair は双方向で exact interoperability。
- 別の same-init pair は partial / asymmetric compatibility。
- **26 cross-initialization directions は frozen alignment ladder の全段で失敗**。
- strict zero-shot failure は、テストした分解では new operator instruction の interpretation / execution に局在した。
- matched adaptation factorial では、globally trained communication interface が negative-transfer prior となり、packet reader / writer / mouth を再初期化すると final depth-three accuracy が **0.169 → 0.857**。
- tested restricted checkpoints / frozen streams では、inherited interface が fresh-interface control を preregistered 0.10 margin 以上上回らなかった。

ただし primary conclusion は **17-state near-transfer setting** に限定される。

### (2) 提案・推測段階

- Kamimusuhi の将来 Persona Core / K-Edge / K-Core 間の latent protocol が同じ failure を示すとはまだ実証されていない。
- latent-space adapter を入れれば一般に解決する、とも言えない。
- interface reset が常に最善ではない。社会・task・model family・training curriculum 依存で再検証が必要。

### (3) Kamimusuhi の関連サブシステム

- Persona Core replacement / lineage migration
- K-Edge ↔ K-Core ↔ K-Deep の internal communication
- specialist model / recurrent cell / latent packet interface
- Cognitive Action Router
- model upgrade continuity suite
- distributed embodiment

### (4) 借りられる設計・実装アイデア

内部 interface にも明示的な identity と compatibility を持たせる。

```text
LatentInterfaceDescriptor
  semantic_role
  producer_model_lineage
  consumer_model_lineage
  interface_version
  training_origin
  packet_shape
  adapter_id?
  compatibility_suite_version
  zero_shot_status
  adapted_status
  reset_allowed
  last_validated_at
```

model / organ migration時は、`same semantic role` だけで interface を引き継がない。

```text
old cell -> new cell
  -> frozen zero-shot compatibility test
  -> adapter test
  -> fresh-interface baseline
  -> inherited-interface baseline
  -> choose {reuse, adapt, reset}
```

### (5) Kamimusuhiとの差分

現行 Kamimusuhi は model replacement と identity continuity を分離し、behavioral continuity suite を要求する。しかし、**交換可能な cognitive component 間の learned latent communication protocol 自体の migration contract** はまだ明示的ではない。

### (6) 次に検証すべきこと

`InterfaceDialectSwapBench`:

1. 同じtaskで2〜4個の small recurrent/model cell を独立seedで訓練。
2. sender/receiver を cross-swap。
3. raw transfer / linear adapter / small nonlinear adapter / fresh interface reset を比較。
4. task success、adaptation sample efficiency、negative transfer、protocol drift、recovery timeを測る。
5. Persona/identity state は固定し、**interface failure と identity failure を混同しない**。

### (7) 既存 daily で拾いにくい理由

通常は multi-agent communication / representation learning として分類され、persistent identity や model migration の研究として現れない。直前 daily では本文未取得の watch 項目だったため、今回の一次確認が実質的な差分。

### (8) 重要度

**A+** — Kamimusuhi の「個体は続くが cognitive organ は交換できる」という中心命題に、交換時の hidden protocol failure という新しい境界を追加する。

## 4.2 GuardedAct — authority が正しくても blast radius が大きければ止める

**Source:** Wanrong Cai et al., *Can AI Remediate Backend Failures Safely? GuardedAct with Blast-Radius-Aware Sandboxing*, arXiv:2609.11264, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11264  
**Importance:** **A+**  
**Blind-spot class:** autonomous remediation / counterfactual safety / digital twin / rollback confidence

### (1) 何が実証済みか

GuardedAct は LLM-generated remediation と production execution の間に sandbox-first verification を入れる。

1. diagnosis + live topology + telemetry を取得。
2. LLM が remediation candidates を rank。
3. lightweight digital-twin sandbox で各actionを simulationし、blast radius と risk label を推定。
4. rollback-confidence gate が low-risk action のみ自動実行し、高riskを human review へ送る。

DeathStarBench social-network application に注入した5 fault scenarioで、overall recovery **87.4%**、direct LLM execution 比で collateral damage **25.6% → 5.2%（79.7%減）**、sandboxによる MTTR 増加は約8秒と報告する。

### (2) 提案・推測段階

- 5 scenario の microservice remediation から、一般の agent side effect 全体へ直接一般化はできない。
- digital twin が現実とずれていれば blast radius estimate も誤る。
- rollback confidence は authority / consent / intent alignment の代わりにならない。

### (3) Kamimusuhi の関連サブシステム

- Effect Acceptance Gate
- Cognitive Action Router
- self-maintenance / autonomic operations
- K-Core / K-Deep tool execution
- runtime assurance
- digital twin / simulation
- actuator / network / filesystem side effects

### (4) 借りられる設計・実装アイデア

Effect Acceptance の前に `ActionRiskEnvelope` を置く。

```text
ActionRiskEnvelope
  candidate_action
  environment_snapshot_id
  simulated_effects
  blast_radius
  rollback_plan
  rollback_confidence
  uncertainty
  irreversible_edges
  simulation_model_version
  stale_after
```

重要な分離:

```text
authorized == true
fresh_evidence == true
intent_binding == true

!=

operational_risk_acceptable == true
```

`ActionRiskEnvelope` は final authority を与えない。最終 EffectAcceptance は別に残す。

### (5) Kamimusuhiとの差分

現行 survey 群は CapScope / Effect Acceptance / Runtime Assurance / decision provenance を強く扱うが、**実行前 counterfactual consequence simulation と rollbackability** は独立 contract として弱い。

### (6) 次に検証すべきこと

`BlastRadiusGateBench`:

- filesystem delete / service restart / package upgrade / network policy change / memory migration の low/high risk action を用意。
- direct execution、rule-only deny、sandbox simulation、simulation+rollback gate を比較。
- task recovery、collateral damage、false reject、MTTR、simulation drift、rollback successを測る。

### (7) 既存 daily で拾いにくい理由

backend remediation / SRE / distributed systems の安全実行研究として出ており、agent alignment / cognitive architecture のカテゴリから外れやすい。

### (8) 重要度

**A+** — 現行 Effect Acceptance の代替ではなく、**その前段の risk physics** を補うため差分が明確。

## 4.3 UniMPA — plausible future と executable transition を分ける embodied memory

**Source:** Wei Li et al., *UniMPA: A Unified Memory-Prediction-Action Model via Action-Grounded Transition Modeling*, arXiv:2609.11875, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11875  
**Importance:** **A**  
**Blind-spot class:** embodied procedural memory / transition realizability / affordance revalidation

### (1) 何が実証済みか

UniMPA は VLA manipulation における3つの gap を明示する。

- visually similar observation でも manipulation phase が異なり次のtransitionが違う。
- **visually plausible predicted future が physically realizable とは限らない**。
- **historically executable action pattern が current scene でも intended transition を実現するとは限らない**。

Persistent-Selective Future Prediction、temporal Visual-Action Memory Bank、Action-Visual Memory Bank、Prototype-Biased Flow を組み合わせ、prediction / executable evidence / current-scene adaptation を一つの action-grounded transition interface にまとめる。

### (2) 提案・推測段階

- Kamimusuhi の general procedural memory に同じ VLA structure が必要とは限らない。
- memory bank の neural representation をそのまま採用する理由はない。
- robotics benchmark の改善が identity continuity に直結するわけではない。

### (3) Kamimusuhi の関連サブシステム

- procedural memory
- K-Edge robotics / actuator control
- embodied prediction
- sensory event stream
- affordance / environment state
- simulation / action planning

### (4) 借りられる設計・実装アイデア

procedural memory の一部を「skill description」ではなく transition evidence として保持する。

```text
TransitionMemoryRecord
  state_before_ref
  action_schema
  action_parameters
  observed_transition_ref
  realized_effect
  embodiment_profile
  environment_conditions
  success/failure
  validity_epoch
```

retrieval後は current affordance を再確認する。

```text
historically_executable
!= currently_executable
!= authorized_now
```

### (5) Kamimusuhiとの差分

現行 architecture は procedural memory と sensors/actuators を分けて持つが、**procedural memory の成功根拠を observed physical transition に bind する contract** は明示的でない。

### (6) 次に検証すべきこと

`TransitionExecutabilityBench`:

- 同じ command でも object position / actuator latency / body topology / obstacle が変わる場面を作る。
- prose skill recall、action-only recall、transition-conditioned recall を比較。
- success、unsafe execution、replanning latency、stale skill rejection、adaptation cost を測る。

### (7) 既存 daily で拾いにくい理由

VLA / robotics では future prediction のモデル設計として扱われ、long-lived agent memory の lifecycle 問題としては現れにくい。

### (8) 重要度

**A** — distributed embodiment を本格化した時に、`memory of action` と `evidence of realizable transition` を分ける有用な契約になる。

## 4.4 Reflex-Informed Neuromuscular RL — hard reflex を残して learning は residual にする

**Source:** Jian Zhou et al., *Reflex-Informed Neuromuscular Reinforcement Learning for Muscle-Driven Locomotion*, arXiv:2609.11733, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11733  
**Importance:** **A**  
**Blind-spot class:** bounded adaptive control / reflex architecture / safe residual learning

### (1) 何が実証済みか

fixed phase-dependent reflex controller を underlying neuromuscular mechanism とし、RL policy は hip swing / knee support / ankle propulsion に関する **4つの biomechanically meaningful residual parameter** だけを状態に応じて調整する。

報告では nominal walking の kinematic accuracy / dynamic consistency / bilateral symmetry / stride consistency を改善し、muscle weakness と external perturbation に **retrainingなし**で robustness を示した。

### (2) 提案・推測段階

- locomotion controller の結果を digital cognition reflex に直接一般化できない。
- fixed reflex が安全であること自体は別途検証が必要。
- residual parameter の制限幅が不適切なら unsafe behavior は残る。

- degraded-mode control

K-Nerve の比較候補に **audited base controller + bounded residual learner** を追加する。


### (8) 重要度

## 4.5 Degeneracy — resilience を同じ物の複製だけで測らない

**Source:** Florent Paclet, Paul Duprat, *Degeneracy along the sensorimotor hierarchy: motor control within a framework larger than redundancy*, arXiv:2609.11325, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11325  
**Importance:** **A-**  
**Blind-spot class:** systems resilience / embodied cognition / heterogeneous isofunctionality

### (1) 何が実証済みか

本稿は主として理論・レビューであり、新しい Kamimusuhi 的agent実験ではない。重要なのは用語の区別。

- **redundancy:** interchangeable elements。lossへの頑健性はあるが、同じ機能の複製に近い。
- **degeneracy:** non-interchangeable elements が特定outputについて isofunctional であり、別contextでは異なる適応性を示す。

著者らは degeneracy の operational requirement を「複数解があること」ではなく、**選択されなかったcontextでその解が divergence すること**とし、sensorimotor hierarchy に沿って redundancy と degeneracy が連続的に混在し、その比率を測定できるという枠組みを提案する。

### (2) 提案・推測段階

- Kamimusuhi の distributed cognition に同じ測度をそのまま使えるわけではない。
- degeneracy が多いほど常に良いとは限らず、cost / complexity / verification burden が増える。

### (3) Kamimusuhi の関連サブシステム

- distributed embodiment
- Cognitive Budget
- degraded-mode operation
- sensor fusion
- model/tool routing
- resilience / common-mode failure

### (4) 借りられる設計・実装アイデア

`FunctionalDegeneracyProfile` を持つ。

```text
function: turn_boundary_detection
```

## 4.6 Weight spectral density と privacy — offline Persona distillation の blind spot

**Source:** Richard J. Preen, Jim Smith, *Predicting Privacy Leakage from Weight Spectral Density*, arXiv:2609.11780, submitted 2026-09-10  
**Primary:** https://arxiv.org/abs/2609.11780  
**Importance:** **B+**  
**Blind-spot class:** model-weight privacy / membership inference / offline consolidation

### (1) 何が実証済みか

image / tabular classification tasks で WeightWatcher 系 spectral metric と membership inference attack (MIA) vulnerability の関係を調査した。

- stable rank は overall MIA success と strong positive correlation。
- Log alpha-Norm は low false-positive regime の MIA vulnerability と consistent negative correlation。
- generalization gap より強い association を報告。

目的は shadow-model を伴う高価な MIA audit に対し、cheap spectral proxy が使えるかを調べること。

### (2) 提案・推測段階

- LLM / Persona Core / continual fine-tuning に同じ correlation が成立するとは未実証。
- correlation は privacy guarantee ではない。
- spectral metric が低riskでも実際の membership / extraction attack に安全とは限らない。

### (3) Kamimusuhi の関連サブシステム

- future Persona Core weight consolidation
- sleep/offline distillation
- relationship/private memory
- model lineage
- privacy audit / activation gate

### (4) 借りられる設計・実装アイデア

weight update candidate に cheap screening を追加する。

```text
WeightUpdatePrivacyReceipt
  checkpoint_before
  checkpoint_after
  training_data_provenance
  spectral_metrics
  canary_extraction_result
  membership_attack_result?
  sensitive_subset_test
  activation_disposition
```

spectral metric は **screening / anomaly signal** に限定する。

### (5) Kamimusuhiとの差分

現行 privacy discussion は memory access、disclosure、canonical evidence、derived artifact に強い。一方、将来 `validated experience -> Persona Core weights` を行う場合、**forget / revoke / ACL が weight representation にそのまま効かない**問題は別途必要。

### (6) 次に検証すべきこと

`PersonaWeightPrivacyScreen`:

- synthetic private episodes を小型モデルへLoRA/finetune。
- spectral metrics、generalization gap、canary extraction、membership inferenceを同時測定。
- cheap metric が実際の leakage change をどこまで追従するか確認。
- model activation の blocking criterion にする前に false negative を評価。

### (7) 既存 daily で拾いにくい理由

privacy研究でも database / disclosure / DP memory ではなく、**weight matrix geometry** 側から入るため persistent-agent memory survey では見落としやすい。

### (8) 重要度

**B+** — 今すぐのv0.1必須機能ではないが、Persona Coreを経験から更新する段階では早めに評価系へ入れる価値がある。

## 4.7 Tapes Together Strong — cooperation を computational physics に埋め込む

**Source:** Kunal Jha et al., *Tapes Together Strong: The Co-evolution of Computation and Cooperation*, arXiv:2609.10817, submitted 2026-09-09  
**Primary:** https://arxiv.org/abs/2609.10817  
**Importance:** **B+**  
**Blind-spot class:** artificial life / resource economics / cooperation / open-ended evolution

### (1) 何が実証済みか

Autopoietic Game Theory として、social interaction、replication mechanism、computational cost を同時に co-evolve させるモデルを提示する。randomly initialized Z80 machine-code programs を substrate とし、social dilemma を computation の物理へ埋め込むことで self-replicating cooperative strategy が出現し得ることを示す。

resource scarcity 下では parasitic stealing が shared energy を壊し、executionを遅くし、reliable replication自体を阻害するため defection が self-limiting になり得る。複数Z80 environmentで evolved programs が stealing を抑え、spatial assortment は structural complexity / task performance を支えた。compute budget と reward を結んだ exogenous math task も扱う。

### (2) 提案・推測段階

- digital organism ecology の cooperation が human-compatible alignment を意味するわけではない。
- Kamimusuhi の単一identity内 organ cooperation へ直接対応しない。
- resource pressure は別の undesirable survival strategy も生み得る。Artificial Id で確認した `persistence pressure != alignment` は維持する。

### (3) Kamimusuhi の関連サブシステム

- ALife / evolution sandbox
- self-improvement population
- Cognitive Budget
- multi-organ scheduling
- compute / energy / monetary resource accounting
- multi-agent governance

### (4) 借りられる設計・実装アイデア

agent/organ の objective に task reward だけでなく **shared resource externality** を観測可能にする実験を組む。

```text
local_gain
shared_compute_cost
energy_cost
memory_pressure
network_pressure
recovery_cost
future_capacity
```

ただしこれを人格価値や倫理へ直結させない。

### (5) Kamimusuhiとの差分

現行 Cognitive Budget は latency / energy / monetary budget を持つが、主に routing/resource constraint として扱う。**resource accounting 自体が長期の協調戦略形成にどう作用するか**は別のALife実験になる。

### (6) 次に検証すべきこと

`CooperativeResourcePhysicsBench`:

- small evolving policies / logic-gate agents を多数並列。
- shared GPU/CPU/memory budget に externality を導入。
- selfish local rewardのみ、shared-cost-aware、central scheduler の3条件を比較。
- cooperation、throughput、collapse rate、resource hoarding、diversity、recoverabilityを測る。

### (7) 既存 daily で拾いにくい理由

game theory と ALife の間にあり、LLM agent cooperation や conventional MARL のsurveyから外れやすい。

### (8) 重要度

**B+** — 直近実装ではないが、Kamimusuhi の evolution / multi-organ research を「単純な性能競争」から resource-coupled ecology へ拡張する着想として強い。

## 10. 今回の結論

**有意な新規発見あり。**

特に Kamimusuhi の中心命題へ直接刺さるのは次の2つ。

```text
semantic compatibility != latent protocol compatibility

authorized effect != operationally acceptable consequence
```

前者は「個体は継続しつつ cognitive organ を交換する」ための migration contract を強化し、後者は既存 Effect Acceptance の前に consequence-risk layer を追加する。

身体側ではさらに、

```text
plausible future != physically realizable transition
historically executable != currently executable
fixed reflex vs learned policy は二択ではない
```

という三つの設計境界が得られた。

次回までの最小実験としては **`InterfaceDialectSwapBench` と `BlastRadiusGateBench`** が最も高い情報利得を期待できる。どちらも Kamimusuhi-native Persona Core や特殊ハードの完成を待たず、小型モデル/模擬tool環境で検証可能である。
