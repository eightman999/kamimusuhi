### A — Projection-Aligned Context Budget & Stable Hydration Frontier

Source: OpenClaw #159799  
https://github.com/openclaw/openclaw/issues/159799

1. **実証**: stored transcript bytesをtoken budget由来capで切る実装により、model-visible約108K/179.5K tokensでも古い26 eventsがhydration対象外になったfield/source repro。media/metadataがstorage bytesを膨らませ、frontierの毎turn移動でprefix cache missも観測。
2. **未確定**: byte cap廃止が正解とは限らず、効果量はbackend依存。
3. **関係**: Global Workspace、episodic/session memory、Cognitive Budget、multimodal、graceful forgetting。
4. **借用**: storage / projection / compute budgetを分離し、hydration frontierをstable generation+hysteresisで管理。
5. **差分**: 既存Multimodal Replay Horizonより一段下で、**測定representationの不一致がforgettingとlatencyを同時悪化**させる。
6. **検証**: `ProjectionAlignedHydrationBudgetBench-v0`。stored/projected/token/KV基準でrecall・truncation・cache hit・TTFTを比較。
7. **拾いにくさ**: memory / storage / inference servingの境界。
8. **重要度**: **A**。

### A — Atomic Memory-Capture Reservation & Publication

Source: OpenClaw #159826  
https://github.com/openclaw/openclaw/issues/159826

1. **実証**: concurrent session resetが同じ空きfilenameを選び、後のwriteで相互上書き。保存されたruntime evidenceでは3 captures中1のみ残り、6 contenders×15 roundsで90中75 captures喪失。current sourceにもselection/publication分離構造が残るとの報告。
2. **未確定**: current-main runtimeはfresh rerun未実施。exclusive createだけで全backend問題が閉じるわけではない。
3. **関係**: DialogueSession、offline consolidation、episodic capture、provenance、recovery。
4. **借用**: `RESERVED -> WRITING -> VALIDATED -> PUBLISHED`。artifact identityをexclusive/transactionalに確保しprovenanceも同じreservationへbind。
5. **差分**: canonical commitでなく**派生memory artifactのoutput identity reservation**のrace。
6. **検証**: `ConcurrentMemoryCapturePublicationBench-v0`。多重reset、same timestamp、crash/restartでcapture survival・collision・provenance mismatchを測る。
7. **拾いにくさ**: memory semanticsとfilesystem/DB atomicityの境界。
8. **重要度**: **A**。

### B watch — Dependence-Aware Confidence Composition

Sources: IROS 2026 workshop / Baral, arXiv:2609.23731  
https://rethinking-uncertainty.github.io/  
https://arxiv.org/abs/2609.23731

1. **実証**: modular robot prediction simulationで、各estimatorが単体ではwell-calibratedでもerror correlationによりsystem-level uncertaintyがずれる。joint covariance modelingはdownstream calibrationを改善、dependence-robust boundsは安全性と引換えに保守性を増すと報告。9/27 IROS workshop accepted paper。
2. **未確定**: robotics covarianceをLLM delegate confidenceへ直接転用はできない。
3. **関係**: K-Core/K-Deep integration、delegation、sensor fusion、epistemic admission。
4. **借用**: resultへ calibration_domain / evidence_ids / dependency_group / shared_upstream lineage を付け、同じretrieval/model/preprocessを共有する結果を独立票と仮定しない。
5. **差分**: provenance/calibrationは既出だが、**marginal calibrationがcompositionで保存されない**点は未収載。
6. **検証**: `ComposedUncertaintyDependenceBench-v0`。independent/duplicated evidence、same model/different model、shared retrievalでECE/Brier/false high-confidenceを比較。
7. **拾いにくさ**: uncertainty / multi-agent voting / provenanceの交差領域。
8. **重要度**: **B watch**。

## 結論

今回の芯は **「どのrepresentationを測って何を守るか」を揃えること**。canonical storage、reasoner-facing projection、KV/prefill/latency/energy/moneyは別resource domainである。

もう一つは publication discipline。  
`candidate observed != identity reserved`  
`component prepared != generation published`

最後に、局所的な正しさを全体系へそのまま持ち上げない。  
`answer finished != accounting finished`  
`component calibrated != system calibrated`
